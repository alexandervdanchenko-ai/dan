# Дан

**Дан - это язык программирования, на котором программы пишутся по-русски.** Вместо английских слов `if`, `while`, `function` в нём используются привычные `если`, `пока`, `функ`. Готовую программу Дан превращает в обычный файл `.exe`, который запускается на компьютере двойным щелчком, как любая другая программа.

Текущая версия - 0.14. Язык развивается, и в нём ещё будут изменения.

## Как выглядит программа

Вот небольшая программа, которая считает средний балл по оценкам:

```
функ среднее(оценки: [цел]) -> дроб {
    перем сумма = 0
    для о в оценки { сумма += о }
    вернуть дроб(сумма) / оценки.длина
}

пусть оценки = [5, 4, 3, 5]
вывод("Средний балл: " + стр(среднее(оценки)))
```

Если её запустить, на экране появится: `Средний балл: 4.25`.

Что здесь написано, по строкам:

- `функ среднее(...)` - объявляем действие (функцию) с названием «среднее». Оно получает список целых чисел (`[цел]`) и возвращает дробное число (`дроб`);
- `перем сумма = 0` - заводим переменную «сумма», в которую будем складывать оценки;
- `для о в оценки { ... }` - перебираем оценки по одной и прибавляем каждую к сумме;
- `вернуть ...` - делим сумму на количество оценок и отдаём результат;
- `пусть оценки = [5, 4, 3, 5]` - задаём сами оценки;
- `вывод(...)` - печатаем результат на экран.

## Для кого этот язык

- Для тех, кто только начинает программировать и хочет читать код на родном языке, а не переводить каждое слово с английского.
- Для тех, кому нужны быстрые и небольшие программы: Дан собирает программу в машинный код, поэтому она работает быстро и не требует ничего устанавливать у того, кто её запускает.
- Для расчётов: в язык встроена большая математическая библиотека - от школьной арифметики до высшей математики и финансовых расчётов.

## Что умеет язык

**Основное**

- Числа целые (`цел`) и дробные (`дроб`), точные обыкновенные дроби вроде ½ (`рац`), текст (`стр`), значения «да/нет» (`лог`) и списки из любых из них.
- Словари - таблицы вида «название - значение», например телефонная книга `{стр: стр}` или количество товаров `{стр: цел}`; порядок добавления записей сохраняется.
- Переменные, условия (`если`, `иначе`), повторения (`пока`, `для`), собственные функции.
- Свои типы данных, например карточка сотрудника: `тип Сотрудник { фио: стр, оклад: цел }`.
- Функции можно передавать в другие функции и хранить в переменных; списки обрабатываются без циклов: `оценки.отобрать(функ(о) = о >= 4)`.
- Перечисления: значение одного из нескольких видов, например `Круг(радиус)` или `Прямоугольник(ширина, высота)`; оператор `выбор` разбирает их, и Дан проверяет, что ни один вид не забыт.
- Большую программу можно разделить на несколько файлов: `подключить "расчёты.dan"`. Снаружи файла видно только то, что помечено словом `общий`, поэтому имена из разных файлов не путаются.
- Ввод с клавиатуры (`ввод`) и вывод на экран (`вывод`).
- Работа с текстом: поиск, замена, разбиение на части, смена регистра. Русские буквы обрабатываются правильно.
- Школьная запись действий: можно писать `5 × 2 + (5 − 3) : 2` или `а ≠ 0`, как в тетради.

**Математика**

- Школьный курс: делимость, НОД и НОК, дроби, проценты, округление, единицы измерения, уравнения и неравенства, многочлены, геометрия, статистика.
- Высшая и прикладная математика: тригонометрия, логарифмы, производные и интегралы, вероятность, матрицы и векторы, системы счисления и римские цифры.
- Полезное в работе: числа и суммы прописью, расчёт кредита и процентов, оценка вложений (NPV и IRR), компенсация за задержку зарплаты по статье 236 Трудового кодекса РФ, задачи оптимизации (линейное программирование).

**Файлы и данные**

- Чтение и запись файлов и папок, в том числе с русскими названиями.
- Сжатие данных так же сильно, как в архиваторе 7-Zip, и в формате zip.
- Шифрование паролем и zip-архивы с паролем.
- Проверка целостности файлов (контрольные суммы, SHA-256).

**Защита от ошибок**

- Дан проверяет программу ещё до запуска и сообщает об ошибках понятным русским языком. Если в названии допущена опечатка, он подскажет, что, скорее всего, имелось в виду.
- Многие ошибки, которые в других языках проявляются только во время работы программы или вовсе остаются незамеченными, здесь не пройдут молча: обращение к несуществующему элементу списка, слишком большое число, «пустое» значение, перепутанные русские и латинские буквы в названии (например, русская «с» вместо латинской «c»).
- Если значение может отсутствовать, это видно прямо в программе (запись `стр?`), и программист обязан это учесть. Поэтому не бывает внезапных сбоев из-за «пустоты».
- Если действие может не получиться (например, человек ввёл «сорок» вместо числа), это тоже видно в программе: результат записывается как `цел!` - «число или ошибка». Забыть про ошибку нельзя: Дан не соберёт программу, пока для ошибки не указано, что делать, - передать её дальше, подставить запасное значение или сообщить пользователю.

## Установка в Windows

### Быстрый способ

Скачайте файл `установить_windows.ps1` из этого репозитория, откройте окно PowerShell в папке, куда он сохранён, и выполните:

```
powershell -ExecutionPolicy Bypass -File установить_windows.ps1
```

Сценарий сам установит всё необходимое (Python, компилятор C, упаковщик UPX и Git), загрузит проект в папку `D:\проекты\Дан` и проверит, что всё работает. Нужен диск D; если его нет, путь можно поменять в начале файла.

### Вручную

Понадобятся две программы:

1. **Python версии 3.10 или новее** - на нём написан сам Дан.
2. **Компилятор C** (gcc или clang) - он превращает программу в файл `.exe`. В Windows его проще всего установить командой:

   ```
   winget install BrechtSanders.WinLibs.POSIX.UCRT
   ```

   После установки закройте окно командной строки и откройте новое.

Затем скачайте проект (зелёная кнопка «Code» на странице репозитория, пункт «Download ZIP») и распакуйте его.

## Первая программа

1. Откройте любой текстовый редактор, например «Блокнот».
2. Напишите строку `вывод("Привет, мир!")`.
3. Сохраните файл с расширением `.dan`, например `привет.dan`, в кодировке UTF-8 (в «Блокноте» кодировка выбирается в окне сохранения).
4. Откройте командную строку в папке с проектом Дан и выполните:

   ```
   python dan.py запустить привет.dan
   ```

На экране появится `Привет, мир!`. Готовые примеры программ лежат в папке `примеры`, их можно запускать так же.

## Команды

Все команды вводятся в командной строке, открытой в папке проекта:

| Команда | Что делает |
|---|---|
| `python dan.py запустить программа.dan` | собирает программу и сразу её выполняет |
| `python dan.py собрать программа.dan` | создаёт файл `.exe` рядом с программой; его можно передать другим людям |
| `python dan.py проверить программа.dan` | ищет ошибки, ничего не собирая |
| `python dan.py си программа.dan` | показывает, во что Дан перевёл программу (код на языке C) |
| `python dan.py дерево программа.dan` | показывает, как Дан понял структуру программы |
| `python dan.py токены программа.dan` | показывает, на какие слова Дан разбил текст программы |

Последние три команды нужны в основном тем, кто разбирается в устройстве языка.

Дополнительные настройки для `собрать` и `запустить`:

| Настройка | Что делает |
|---|---|
| `--малый` | делает файл программы как можно меньше (обычно он делается как можно быстрее) |
| `--сжать` | дополнительно сжимает готовый `.exe` в 2-3 раза; он запускается как обычно. Нужен упаковщик UPX: `winget install UPX.UPX` |

Например: `python dan.py собрать примеры\факториал.dan --сжать`.

## Как устроен Дан

Это раздел для тех, кому интересно, что происходит «внутри». Когда вы запускаете программу, Дан обрабатывает её по шагам:

| Шаг | Файл | Что происходит |
|---|---|---|
| 1. Разбор на слова | `lexer.py` | текст программы делится на отдельные слова и знаки |
| 2. Разбор структуры | `parser.py`, `uzly.py` | из слов складывается схема программы: где функция, где условие, где повторение |
| 3. Проверка | `proverka.py` | проверяется, что всё написано правильно: числа не складываются с текстом, переменные существуют, функциям передаётся то, что нужно |
| 4. Перевод | `kodogen.py` | программа переводится на язык C |
| 5. Сборка | внешний компилятор C | из кода на C получается готовый файл `.exe` |

Математика находится в файлах `matematika.py` и `vysshaya.py`, работа с файлами, сжатие и шифрование - в `dannye.py` и папке `sreda`.

## Проверка работоспособности

В проекте есть автоматические тесты. Запустить их можно командой:

```
python -m unittest
```

Тесты, которые собирают и запускают программы, требуют компилятора C; без него они пропускаются.

На компьютере с Linux можно проверить и программы, собранные для Windows: `test_windows.py` собирает весь каталог компилятором MinGW и запускает его через Wine. Эта проверка включается переменной `DAN_WINDOWS=1` (нужны пакеты `gcc-mingw-w64-x86-64` и `wine64`).

Устойчивость компилятора проверяет `ustoychivost.py`: он тысячами портит программы каталога и следит, чтобы компилятор на любую из них отвечал понятным сообщением или правильным кодом, а собранные программы не завершались аварийно (`python ustoychivost.py 3000 1 --запуск`). Короткий вариант этой проверки входит в обычные тесты.

## Важно о шифровании

Встроенное шифрование (функции `зашифровать`, `расшифровать`, сжатие и архивы с паролем) подходит для личных задач, но **не является сертифицированным средством защиты информации**. Его нельзя использовать там, где закон требует сертифицированных средств: в государственных информационных системах, в системах, обрабатывающих персональные данные, и в других подобных случаях. Подробнее - в файле `исследование.md`, раздел 4.4.
