# Дан

Компилируемый язык программирования общего назначения с русскими ключевыми словами. Версия 0.6.

```
функ среднее(оценки: [цел]) -> дроб {
    перем сумма = 0
    для о в оценки { сумма += о }
    вернуть дроб(сумма) / оценки.длина
}

пусть оценки = [5, 4, 3, 5]
вывод("Средний балл: " + стр(среднее(оценки)))
```

Что умеет язык:

- типы `цел`, `дроб`, `стр`, `лог`, точные обыкновенные дроби `рац` и списки любых из них (`[цел]`, `[[стр]]`);
- переменные (`пусть`, `перем`), условия (`если`, `иначе`), циклы (`пока`, `для`), функции (`функ`);
- ввод с клавиатуры (`ввод`), вывод (`вывод`), преобразования (`стр`, `цел`, `дроб`);
- школьная запись действий: `5 × 2 + (5 − 3) : 2`, `а ≠ 0`, деление с остатком по школьному определению;
- математическая библиотека по курсу «Математика с нуля»: делимость, НОД и НОК, дроби, округление, единицы измерения, проценты, множества, статистика, геометрия, степени и корни, многочлены, уравнения и их системы, неравенства методом интервалов, модуль;
- файлы и папки (с русскими именами), байты, контрольные суммы и хеш SHA-256;
- сжатие уровня 7-Zip (LZMA2, формат .xz) и zip (DEFLATE, формат gzip), шифрование паролем (ChaCha20-Poly1305), zip-архивы, в том числе с паролем AES-256;
- проверка ошибок до запуска с понятными сообщениями на русском языке;
- компиляция в исполняемый файл: программы работают примерно в 20 раз быстрее аналогичных на Python.

Полное описание языка - в файле `spec.md`, примеры - в папке `примеры`.

## Что нужно для работы

1. **Python 3.10 или новее** (на нём написан компилятор Дан).
2. **Компилятор C: gcc или clang** (он превращает результат в исполняемый файл). В Windows проще всего установить его командой в командной строке:

   ```
   winget install BrechtSanders.WinLibs.POSIX.UCRT
   ```

   После установки нужно открыть новое окно командной строки.

## Как пользоваться

Все команды выполняются в папке `dan`:

| Команда | Действие |
|---|---|
| `python dan.py запустить примеры\факториал.dan` | собрать программу и сразу выполнить |
| `python dan.py собрать примеры\факториал.dan` | собрать исполняемый файл (`.exe` рядом с программой) |
| `python dan.py проверить программа.dan` | найти ошибки, ничего не собирая |
| `python dan.py си программа.dan` | показать полученный код на C |
| `python dan.py дерево программа.dan` | показать дерево программы |
| `python dan.py токены программа.dan` | показать токены |

Параметры для `собрать` и `запустить`:

| Параметр | Действие |
|---|---|
| `--малый` | оптимизировать программу по размеру, а не по скорости |
| `--сжать` | сжать готовую программу упаковщиком UPX (алгоритм LZMA, как в 7z): файл становится в 2-3 раза меньше и запускается как обычно |

Для `--сжать` нужен UPX, в Windows он устанавливается командой `winget install UPX.UPX`.

Программы пишутся в любом текстовом редакторе и сохраняются в кодировке UTF-8 с расширением `.dan`.

## Устройство компилятора

Программа проходит четыре этапа:

| Этап | Файл | Что делает |
|---|---|---|
| Лексер | `lexer.py` | разбивает текст на слова (токены) |
| Парсер | `parser.py`, `uzly.py` | строит дерево программы |
| Проверка | `proverka.py` | проверяет типы, переменные, функции |
| Генератор | `kodogen.py` | переводит дерево в код на C |
| Математика | `matematika.py` | математическая библиотека |
| Данные | `dannye.py`, `sreda/dannye.c` | файлы, сжатие, шифрование, архивы |

Затем компилятор C собирает исполняемый файл. Правила языка описаны в `spec.md`.

## Тесты

```
python -m unittest
```

Тесты выполнения (`test_kodogen.py`) требуют компилятора C и без него пропускаются.
