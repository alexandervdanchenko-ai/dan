# Дан

[![Проверка](https://github.com/alexandervdanchenko-ai/dan/actions/workflows/proverka.yml/badge.svg)](https://github.com/alexandervdanchenko-ai/dan/actions/workflows/proverka.yml)

![Дан - язык программирования на русском языке](.github/обложка.jpg)

**Дан - это язык программирования, на котором программы пишутся по-русски.** Вместо английских слов `if`, `while`, `function` в нём используются привычные `если`, `пока`, `функ`. Готовую программу Дан превращает в обычный файл `.exe`, который запускается двойным щелчком, как любая другая программа.

Текущая версия - 1.8. Программы, написанные для версии 1.0 и новее, будут работать и во всех следующих версиях Дана.

## Главное о языке

- **Понятно.** Код читается на родном языке, а сообщения об ошибках написаны по-русски и подсказывают, как их исправить.
- **Быстро.** Программа собирается в машинный код и не требует ничего устанавливать у того, кто её запускает.
- **Надёжно.** Дан находит многие ошибки ещё до запуска программы.
- **Локальные языковые модели.** Программа на Дане запускает модель GGUF прямо на компьютере, без видеокарты и интернета: ответ целиком, по словам или в виде чата (модуль `модели`, пример `примеры/модель_чат.dan`).
- **Универсально.** На Дане можно писать программы любого назначения: с окнами, документами Word, Excel и PDF, почтой, базой данных. Они работают в Windows, Linux, macOS и в браузере.

## Установка в Windows

Откройте страницу последнего выпуска: https://github.com/alexandervdanchenko-ai/dan/releases/latest, скачайте файл `dan-...-setup.exe` и запустите его. Права администратора не нужны, Python и компилятор C ставить не нужно: всё необходимое уже внутри.

После установки в меню «Пуск» появится папка «Дан»: в ней редактор, учебник «Дан с нуля», справочник и командная строка. Примеры программ лежат в папке «Документы\Дан\примеры». Программу `.dan` можно запустить двойным щелчком или командой в любом окне командной строки:

```
dan запустить программа.dan
dan собрать программа.dan
```

Вторая команда создаёт обычный файл `.exe`, который можно передать другим людям. Упражнения с автоматической проверкой: `dan задачи` и `dan задача 1`.

Установщик и собранные Даном программы не подписаны цифровой подписью, поэтому Windows SmartScreen или антивирус могут предупредить о неизвестном издателе: это ожидаемо. Скачивайте Дан только со страницы выпусков и сверяйте файл с `SHA256SUMS.txt` (команда `certutil -hashfile файл SHA256`); в окне SmartScreen нажмите «Подробнее» и «Выполнить в любом случае».

Новую версию ставит команда `dan обновить`. Официально Дан распространяется только через страницу выпусков.

Для разработки самого Дана (с исходным кодом и тестами) подходит сценарий `установить_windows.ps1`: он ставит Python, компилятор C и Git, загружает проект и собирает компилятор на Дане `semya\dan.exe`.

## Установка в Linux и macOS

Нужны git и компилятор C (gcc или clang). Первая команда загружает выпуск 1.8, компилятор Дана собирается из семени одной командой, Python не нужен:

```
git clone --branch v1.8 --depth 1 https://github.com/alexandervdanchenko-ai/dan.git
cd dan
sh semya/sobrat.sh
semya/dan запустить примеры/факториал.dan
```

Из другой папки компилятор вызывается полным путём: папку проекта (с папками `sreda` и `библиотека`) он находит сам - это папка выше `semya`. Переменная `DAN_HOME` нужна, только если исполняемый файл перенесён в другое место. Библиотеку для модуля «модели» ставит команда `semya/dan модели установить`. Команда `python dan.py` вызывает прежний компилятор на Python: в нём нет возможностей версий 1.5 и новее, он нужен для разработки самого Дана.

Подробное описание языка - в файлах `справочник.md` и `spec.md`, примеры программ - в папке `примеры`. Языковой модели, которая пишет на Дане, достаточно дать файл `llms-full.txt`. Как устроен сам Дан и как участвовать в его разработке - в файле `УЧАСТИЕ.md`. План развития - в файле `ROADMAP.md`.
