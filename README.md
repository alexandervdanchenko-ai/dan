# Дан

**Дан - это язык программирования, на котором программы пишутся по-русски.** Вместо английских слов `if`, `while`, `function` в нём используются привычные `если`, `пока`, `функ`. Готовую программу Дан превращает в обычный файл `.exe`, который запускается двойным щелчком, как любая другая программа.

Текущая версия - 0.22. Язык развивается, и в нём ещё будут изменения.

```
функ среднее(оценки: [цел]) -> дроб {
    перем сумма = 0
    для о в оценки { сумма += о }
    вернуть дроб(сумма) / оценки.длина
}

пусть оценки = [5, 4, 3, 5]
вывод("Средний балл: " + стр(среднее(оценки)))
```

Эта программа выведет на экран: `Средний балл: 4.25`.

## Главное о языке

- **Понятно.** Код читается на родном языке, а сообщения об ошибках написаны по-русски и подсказывают, как их исправить.
- **Быстро.** Программа собирается в машинный код и не требует ничего устанавливать у того, кто её запускает.
- **Надёжно.** Дан находит многие ошибки ещё до запуска программы и не даёт им пройти незамеченными.
- **Универсально.** На Дане можно писать программы любого назначения: от простых расчётов до программ с окнами, работы с файлами, сайтами и базами данных. Программы работают в Windows, Linux, macOS и в браузере.

## Установка в Windows

Скачайте файл `установить_windows.ps1` из этого репозитория, откройте окно PowerShell в папке, куда он сохранён, и выполните:

```
powershell -ExecutionPolicy Bypass -File установить_windows.ps1
```

Сценарий сам установит всё необходимое, загрузит проект в папку `D:\проекты\Дан` и проверит, что всё работает.

## Первая программа

1. Откройте любой текстовый редактор, например «Блокнот», и напишите строку `вывод("Привет, мир!")`.
2. Сохраните файл как `привет.dan` в кодировке UTF-8.
3. В командной строке, открытой в папке проекта, выполните:

   ```
   python dan.py запустить привет.dan
   ```

Чтобы получить готовый файл `.exe`, который можно передать другим людям, используйте команду `python dan.py собрать привет.dan`.

Для Visual Studio Code есть расширение с подсветкой текста и подсказками: файл `редактор/dan-language-0.21.0.vsix`.
