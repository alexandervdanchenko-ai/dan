# Векторы Wycheproof

Наборы тестовых векторов проекта Wycheproof: https://github.com/C2SP/wycheproof (раньше - google/wycheproof), папка `testvectors_v1`, коммит `d17cc89fa5c8f4f4d378b5385ebf75da5d0926c9` от 23.10.2026. Файлы скопированы без изменений. Лицензия - Apache License 2.0, её текст - в файле `LICENSE` этой папки.

Тесты не скачивают векторы: `test_dannye.ТестыWycheproof` читает эти файлы и вызывает функции среды (`sreda/dannye.c`) напрямую. Допустимые векторы (`valid`) должны дать записанный результат, недопустимые (`invalid`) - отказ.

| Файл | Векторов | Что проверяется |
|---|---|---|
| `chacha20_poly1305_test.json` | 325 | `dan_aead_open` (расшифровка: изменённый код подлинности или nonce не из 12 байтов - отказ) и `dan_aead_seal` (шифрование) |
| `chacha20_counter_test.json` | 42 | `dan_chacha20_xor` с начальным счётчиком: 14 векторов ChaCha20 (nonce 12 байтов), из них переход счётчика через 2^32 - отказ; 28 векторов XChaCha20 (nonce 24 байта) - в среде XChaCha20 нет, проверяется только отказ |
| `aes_cbc_pkcs5_test.json` | 216 | блоки AES каждым вариантом (C, AES-NI, ARMv8), режим CBC с дополнением PKCS#5 собран в тесте; в среде AES только шифрует (режим CTR архивов), поэтому для недопустимых векторов (неверное дополнение при расшифровке) проверяется, что шифрование не даёт записанного шифра |
| `hmac_sha256_test.json` | 174 | `dan_hmac256` и сравнение за постоянное время `dan_equal_ct`, в том числе укороченные коды |
| `hmac_sha1_test.json` | 170 | `dan_hmac1` (подлинность в архивах WinZip AES) |
| `pbkdf2_hmacsha256_test.json` | 60 | `dan_pbkdf2_sha256` (ключ шифрования паролем) |
| `pbkdf2_hmacsha1_test.json` | 64 | `dan_pbkdf2_sha1` (ключ архивов WinZip AES), в том числе 16 777 216 повторений |

Векторов AES-CTR и отдельных блоков AES (ECB) в Wycheproof нет; режим CTR архивов проверяется векторами FIPS-197, сверкой вариантов с образцом и архивом из другой программы (`test_dannye.ТестыAES`).
