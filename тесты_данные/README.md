# Данные для тестов

Файлы, которые тесты читают как есть: их создала другая программа, поэтому они проверяют среду Дана независимо от неё самой.

- `winzip_aes.zip` - архив WinZip AES (метод 99, версия AE-2) с тремя файлами `aes128.bin`, `aes192.bin`, `aes256.bin`, зашифрованными ключами AES-128, AES-192 и AES-256 (пароль `Dan-WinZip-AES`, без сжатия). Создан пакетом Python pyzipper 0.4.0. Хеши SHA-256 файлов записаны в `test_dannye.py` (`WINZIP_AES`); тест `ТестыAES.test_архив_winzip_каждым_вариантом` извлекает архив каждым вариантом AES среды.
- `нейро_прежний_проход.txt` - функции прохода пакета модуля `нейро` до потока 24Б (сдвиги, поворот, запись в кэш, внимание и SwiGLU по токенам). Тест `test_neyro.ТестыПрежнегоПрохода` подставляет их в нынешний модуль и сверяет логиты прежнего и нынешнего модулей побитно.
