# 0016. Строка без заголовка

Дата: 2026-11-11

## Контекст

Сторонний разбор предложил хранить длину и признак ASCII в заголовке строки; в профиле задачи «Записи JSON в свои типы» длина строки занимает около 15%.

## Решение

Строка остаётся `const char *` с нулём в конце. Сначала - быстрый путь для ASCII в `dan_str_len` с замером; заголовок - только если этого не хватит.

## Альтернативы

Заголовок строки: затрагивает всю среду C и все модули (план ускорения, Г4).

## Когда пересмотреть

Если быстрого пути не хватит, чтобы задача JSON была не медленнее C в 1,5 раза.
