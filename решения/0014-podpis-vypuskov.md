# 0014. Подпись выпусков и привязка к коммиту

Дата: 2026-11-11

## Контекст

`dan обновить` сверяет суммы `SHA256SUMS.txt` из того же выпуска: при утечке токена GitHub подменяются и файл, и сумма. Владелец поручил решить самому («делай так, как выгодно»).

## Решение

1. Привязка файлов выпуска к коммиту и сценарию сборки через attestations GitHub (`gh attestation verify`), бесплатно. 2. Файл `SHA256SUMS.txt` подписывается ключом Ed25519. Закрытый ключ хранится в секрете окружения GitHub «выпуск», которое требует одобрения владельца (одно нажатие при выпуске); открытый ключ зашит в компилятор, `dan обновить` проверяет подпись (проверку Ed25519 пишем сами в среде). Смена ключа - новый ключ, подписанный старым.

## Альтернативы

Офлайн-ключ на машине владельца (minisign): надёжнее, но ручной шаг с командной строкой в каждом выпуске. Платный сертификат подписи кода: решает и SmartScreen, но стоит денег (решение владельца, вне работ над языком).

## Когда пересмотреть

Если владелец согласится хранить ключ сам - перенести ключ из секрета GitHub на его машину.
