# 0001. Без LLVM: компилятор порождает код C

Дата: 2026-11-05

## Контекст

Для скорости и переносимости обычно берут LLVM. Дан с самого начала порождает код C и собирает его gcc, clang или zig.

## Решение

LLVM не используется. Компилятор порождает код C, который собирают распространённые компиляторы C.

## Альтернативы

LLVM как основной путь: зависимость в сотни мегабайт, другая для каждой системы, а на целевых задачах выигрыша нет. Свой порождатель машинного кода: огромная работа и потеря поддержки ARM, RISC-V и WebAssembly, которые код C даёт сразу.

## Когда пересмотреть

Если замеры покажут, что код C не даёт нужной скорости на целевых задачах, а LLVM даёт заметно больше на тех же задачах.
