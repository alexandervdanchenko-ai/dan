# Журнал решений

Здесь записаны сознательные решения проекта: что выбрано, почему, какие варианты отвергнуты и когда решение стоит пересмотреть. Журнал нужен, чтобы следующий участник (человек или программа-агент) не спорил заново с уже принятым решением и не нарушил его случайно.

Одно решение - один файл `NNNN-имя.md`: четыре цифры по порядку и короткое имя латиницей. Образец:

```
# NNNN. Заголовок

Дата: ГГГГ-ММ-ДД

## Контекст
## Решение
## Альтернативы
## Когда пересмотреть
```

Решение не удаляют и не переписывают задним числом: отменённое решение получает строку «Заменено решением NNNN» под датой, а новое решение - свой файл. Каждая строка таблицы «Чего не делаем» в `ROADMAP.md` ссылается на запись журнала; это и устройство файлов проверяет `test_resheniya.py`.
