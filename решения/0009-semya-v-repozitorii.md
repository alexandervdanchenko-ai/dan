# 0009. Семя `semya/dan.c` хранится в репозитории

Дата: 2026-11-11

## Контекст

Семя (код C компилятора на Дане, около 8 МБ) менялось 77 раз; сжатая история - 62 МБ.

## Решение

Семя хранится в каждом коммите: компилятор собирается без Python из любого коммита.

## Альтернативы

Хранить семя только в выпусках: дешевле по месту, но коммит между выпусками без Python не собрать.

## Когда пересмотреть

Если сжатая история репозитория превысит 300 МБ - хранить семя только в метках выпусков.
