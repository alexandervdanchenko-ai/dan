# 0008. Компилятор на Python заморожен

Дата: 2026-10-31

## Контекст

Два компилятора (на Python и на Дане) давали побайтно одинаковый результат; держать оба в развитии вдвое дороже.

## Решение

Компилятор на Python заморожен (этап 17а, `zamorozka.py`, метка `python-zamorozhen`). Язык, сообщения и порождаемый код меняются только в папке `сам`. Python остаётся эталоном прежнего поведения.

## Альтернативы

Удалить компилятор на Python: потеря эталона для сверки. Развивать оба: двойная работа.

## Когда пересмотреть

Если эталон перестанет ловить ошибки (все сверки только предупреждают) - удалить его вместе со сверками.
