# 0013. Независимый разбор перед каждым выпуском

Дата: 2026-11-11

## Контекст

Изменения пишет языковая модель, владелец не успевает прочитать их все.

## Решение

Перед каждым выпуском изменения выпуска разбирает отдельный агент, который не писал этот код: архитектурные ошибки, нарушения `принципы.md` и `гарантии.md`, непроверенные заявления. Итог - документ в проекте и задачи в план.

## Альтернативы

Разбор только владельцем: не успевает. Без разбора: ошибки копятся.

## Когда пересмотреть

Не пересматривается.
