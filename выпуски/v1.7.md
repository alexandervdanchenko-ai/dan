Дан - язык программирования, на котором программы пишутся по-русски и собираются в обычные исполняемые файлы.

## Установка в Windows

Скачайте ниже, в разделе «Assets», файл `dan-1.7-setup.exe` и запустите его. Права администратора не нужны. Python, компилятор C и другие программы ставить не нужно: всё необходимое уже внутри установщика. Если Дан уже установлен, установите эту версию поверх него (или выполните `dan обновить`).

В Linux и macOS Дан собирается из исходного кода тремя командами - они в README, в разделе «Установка в Linux и macOS».

## Главное

**Собственный движок языковых моделей на Дане.** Модуль `нейро` читает файл модели GGUF, разбивает текст на токены и порождает ответ сам, без llama.cpp. Веса в форматах Q4_0, Q4_K, Q5_K и Q6_K (модели Q4_K_M и подобные) считаются прямо из файла векторными ядрами, кэш ключей и значений хранится в половинной точности, запрос подаётся пакетами. На машине GitHub (AMD EPYC, 4 потока) модель Mistral 7B Q4_K_M выдаёт 7-7,5 слов в секунду - 0,87-0,90 предела, который задаёт скорость чтения памяти; цель плана развития - не ниже 0,8. Ответ сверяется с llama.cpp: на тех же весах жадный ответ совпадает. Чтение длинного запроса пока в 3-5 раз медленнее llama.cpp - это задача следующего выпуска. Цифры и способ замера - в `замеры/результаты.md`.

**Один компилятор, поставка без Python.** Все команды - и сборка, и песочница (`dan песочница`), и сервер языка для редакторов (`dan сервер`), и `dan обновить`, и параметры `--веб`, `--для=`, `--сжать` - выполняет компилятор, написанный на самом Дане. В установщике для Windows больше нет Python: `dan.exe` - это компилятор на Дане, собранный из семени. Установщик стал меньше (около 57 МБ вместо 68), переносной архив - около 96 МБ вместо 111. Расширение для VS Code запускает `dan сервер` напрямую.

## Новое в языке

- Шестнадцатеричные и двоичные числа: `0xFF`, `0b1010` (в русской раскладке `0х1F` и `0д1010`), `_` между цифрами.
- Побитовые действия над `цел`: `биты_и`, `биты_или`, `биты_искл`, `биты_не`, `сдвиг_влево`, `сдвиг_вправо`, `сдвиг_вправо_логический`.
- Длинное выражение можно перенести после знака действия в конце строки (`а +`), скобки не нужны.
- Вызов под `!` (`д = шаг(д)!`) отдаёт значение без копии: цикл над записью с большим массивом стал в сотни раз быстрее и не держит вторую копию в памяти.
- `напечатать(текст)` - вывод без перевода строки.
- Шаг `параллельно для` может читать общий массив по любому индексу.
- Векторные ядра для весов llama.cpp: `матвек_q4_0`, `матвек_q4k`, `матвек_q5k`, `матвек_q6k` и разворачивание `из_q4k` и подобные.
- `путь_программы()`, ввод и вывод байтов как есть, соединения TCP на 127.0.0.1.

Программы, написанные для версий 1.0-1.6.1, работают в версии 1.7 без изменений.

## Проверка выпуска

Каждый выпуск теперь проверяется так, как его получит пользователь: на чистых машинах Windows, Linux (x86-64 и ARM) и macOS скачиваются файлы со страницы выпуска, сверяются с `SHA256SUMS.txt`, Дан ставится командами из README и собирает программы с массивами, `параллельно для` и моделью.

## Файлы

- `dan-1.7-setup.exe` - установщик для Windows (рекомендуется);
- `dan-1.7-windows.zip` - Дан без установки;
- `install_windows.ps1` - установка для разработки самого Дана (с исходным кодом, Python и тестами);
- `dan-language-1.0.0.vsix` - расширение для редактора VS Code;
- `llama-b12190-linux-x64.zip`, `llama-b12190-linux-arm64.zip`, `llama-b12190-macos-arm64.zip`, `llama-b12190-windows-x64.zip` - библиотека llama.cpp для модуля `модели` (ставится командой `dan модели установить`; в установщике для Windows уже есть);
- `SHA256SUMS.txt` - контрольные суммы файлов.
