Дан - язык программирования, на котором программы пишутся по-русски и собираются в обычные исполняемые файлы.

## Установка в Windows

Скачайте ниже, в разделе «Assets», файл `dan-1.6.1-setup.exe` и запустите его. Права администратора не нужны. Python, компилятор C и другие программы ставить не нужно: всё необходимое уже внутри установщика. Если Дан 1.5 или 1.6 уже установлен, установите эту версию поверх него (или выполните `dan обновить`).

## Что исправлено

**В Windows не работали возможности версий 1.5 и 1.6.** Установщик и переносной архив для Windows версий 1.5 и 1.6 содержали прежний компилятор на Python, а всё новое в языке с версии 1.5 есть только в компиляторе, написанном на самом Дане. Поэтому у пользователей Windows не работали плотные массивы (`массив(дроб32, 3, 0.5)` давал ошибку «функция «массив» не объявлена»), векторные функции (`скаляр`, `матвек` и другие), `параллельно для`, модуль `модели` и команды `dan модели установить` и `dan модели проверить`, хотя описания выпусков 1.5 и 1.6 их обещали. Проверка выпуска этого не заметила: установленный Дан собирал только программы без новых возможностей. Приносим извинения.

Что изменилось в версии 1.6.1:

- В установщике и архиве есть компилятор на Дане, собранный из семени тем же компилятором C (zig), что лежит в поставке. Команда `dan` передаёт ему все его команды: `запустить`, `собрать`, `проверить`, `тестировать`, `модели` и остальные. Песочница, сервер языка для редакторов, `dan обновить` и параметры `--веб`, `--для=`, `--сжать` по-прежнему выполняет прежняя часть на Python, но программу и тогда переводит компилятор на Дане.
- Модуль `модели` в Windows не загружал ни одной модели: программа останавливалась (0xC0000409), а если библиотека llama.cpp находилась через `PATH` (так после установщика) - сообщала «no backends are loaded». Библиотека llama.cpp для Windows пересобрана с общей для всех её частей средой C (рядом лежат `vcruntime140.dll` и `msvcp140.dll`, ставить ничего не нужно), а варианты для процессора ищутся рядом с найденной `llama.dll`. Эти ошибки нашла новая проверка выпуска.
- `dan --версия` показывает, какой компилятор выполняет команды.
- Проверка каждого выпуска на чистой Windows теперь собирает и выполняет установленным Даном программы с плотными массивами, векторными функциями, `параллельно для` и модулем `модели` (на крошечной модели GGUF) и выполняет `dan модели проверить`.
- Установка для разработки (`install_windows.ps1`) собирает компилятор на Дане из семени; README описывает установку в Linux и macOS из семени (`sh semya/sobrat.sh`).

Язык не изменился: программы, написанные для версий 1.0-1.6, работают в версии 1.6.1 без изменений. В Linux и macOS, где компилятор собирается из семени, исправление ничего не меняет.

## Файлы

- `dan-1.6.1-setup.exe` - установщик для Windows (рекомендуется);
- `dan-1.6.1-windows.zip` - Дан без установки;
- `install_windows.ps1` - установка для разработки самого Дана (с исходным кодом, Python и тестами);
- `dan-language-1.0.0.vsix` - расширение для редактора VS Code;
- `llama-b12190-linux-x64.zip`, `llama-b12190-linux-arm64.zip`, `llama-b12190-macos-arm64.zip`, `llama-b12190-windows-x64.zip` - библиотека llama.cpp для модуля `модели` (ставится командой `dan модели установить`; в установщике для Windows уже есть);
- `SHA256SUMS.txt` - контрольные суммы файлов.
