Дан - язык программирования, на котором программы пишутся по-русски и собираются в обычные исполняемые файлы.

## Установка в Windows

Скачайте ниже, в разделе «Assets», файл `dan-1.14-setup.exe` и запустите его. Права администратора не нужны. Python, компилятор C и другие программы ставить не нужно: всё необходимое уже внутри установщика. Если Дан уже установлен, установите эту версию поверх него (или выполните `dan обновить`).

В Linux и macOS Дан собирается из исходного кода тремя командами - они в README, в разделе «Установка в Linux и macOS».

## Главное

**Подписанные выпуски.** Начиная с 1.14 файл контрольных сумм выпуска подписан ключом Ed25519 (`SHA256SUMS.txt.sig`), а `dan обновить` проверяет подпись открытым ключом, вшитым в компилятор: подменённый или неподписанный выпуск 1.14 и новее (в том числе пробный) не ставится. Файлы выпуска также привязаны к коммиту и сценарию сборки GitHub: `gh attestation verify файл --repo alexandervdanchenko-ai/dan`. Поставка для Windows собирается воспроизводимо: из одного коммита получаются те же файлы байт в байт.

**Многострочные и сырые строки.**

```
функ письмо(имя: стр) -> стр {
    вернуть """
        Здравствуйте, "уважаемый" клиент!
          Строка с отступом в два пробела.
        """ + имя
}
пусть путь = #"C:\папка\файл.txt"#
```

Отступ закрывающих кавычек убирается из каждой строки текста; в сырой строке `#"..."#` (и `#"""` ... `"""#`) обратная косая черта не обрабатывается (раздел 2.6 `spec.md`).

**Модели как инструмент разработки.** Сервер Model Context Protocol `dan mcp` даёт программам-агентам (Claude Code, Codex и другим) проверку, исправление, сборку, тесты и справку по языку; `dan новый имя` создаёт проект с `AGENTS.md`; набор `оценка_моделей` - 70 задач с проверками, чтобы сравнивать модели на Дане. В модуле `нейро` генерацию можно прервать и продолжить с того же места (`м.начать_ответ`, `м.генерировать`); на этом построена показательная программа `показательные/чат_в_окне.dan` - локальный чат с моделью в окне, без llama.cpp и сети.

**Надёжность компилятора.** Компилятор на Дане проверяют теперь и так:

- фаззинг самого компилятора (лексер, разбор, проверка, порождение, форматирование) на случайных текстах программ; первая находка исправлена: на глубоко вложенном тексте компилятор останавливался с ошибкой выполнения, теперь он работает со стеком 64 МБ на всех системах и за пределами вложенности (раздел 2.11) отвечает сообщением с местом;
- компилятор, собранный с AddressSanitizer и UndefinedBehaviorSanitizer, переводит сам себя и все программы каталога;
- выключатели оптимизаций (`DAN_BEZ_PERENOSA=1`, `DAN_BEZ_DIAPAZONOV=1`) дают тот же вывод программ;
- метаморфный фаззинг `параллельно для`: вывод не зависит от числа потоков и совпадает с обычным `для`, ThreadSanitizer гонок не видит;
- холодная пересборка из метки выпуска: компилятор из семени переводит себя в то же семя в двух поколениях и проходит тесты с пустым кэшем.

**Сжатие** документов с картинками быстрее: `сжать_gzip` на уровнях 1-6 проходит несжимаемые участки в 1,6-2,1 раза быстрее при почти том же размере, уровень 9 даёт прежние байты (`замеры/результаты.md`).

**Журнал решений** (папка `решения`): 17 сознательных решений проекта - почему без LLVM, JIT, сборщика мусора, async/await и других - с условиями пересмотра.

## Новое в языке

- Многострочные `"""` ... `"""` и сырые `#"..."#`, `#"""` ... `"""#` строки (раздел 2.6).
- Пределы вложенности текста программы (раздел 2.11): выше того, что собирал компилятор 1.13, поэтому прежние программы собираются.
- Встроенная `подпись_ed25519_верна(данные, подпись, ключ)` (RFC 8032).
- Буквы всех алфавитов Юникода 15.0 в именах (раньше компилятор на Дане знал латиницу, кириллицу, греческие и некоторые другие).

Программы, написанные для версий 1.0-1.13, работают в версии 1.14 без изменений.

## Файлы

- `dan-1.14-setup.exe` - установщик для Windows (рекомендуется);
- `dan-1.14-windows.zip` - Дан без установки;
- `install_windows.ps1` - установка для разработки самого Дана (с исходным кодом, Python и тестами);
- `dan-language-1.0.0.vsix` - расширение для редактора VS Code;
- `llama-b12190-linux-x64.zip`, `llama-b12190-linux-arm64.zip`, `llama-b12190-macos-arm64.zip`, `llama-b12190-windows-x64.zip` - библиотека llama.cpp для модуля `модели` (ставится командой `dan модели установить`; в установщике для Windows уже есть);
- `SHA256SUMS.txt` - контрольные суммы файлов, `SHA256SUMS.txt.sig` - их подпись Ed25519.
