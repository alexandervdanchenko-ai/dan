Дан - язык программирования, на котором программы пишутся по-русски и собираются в обычные исполняемые файлы.

## Установка в Windows

Скачайте ниже, в разделе «Assets», файл `dan-1.2-setup.exe` и запустите его. Права администратора не нужны. Python, компилятор C и другие программы ставить не нужно: всё необходимое уже внутри установщика.

После установки:
- в меню «Пуск» появится папка «Дан» с командной строкой, примерами и справочником;
- примеры программ лежат в папке «Документы\Дан\примеры»;
- программу `.dan` можно запустить двойным щелчком;
- в любом новом окне командной строки работают команды `dan запустить программа.dan` и `dan собрать программа.dan`.

Если устанавливать нельзя, скачайте `dan-1.2-windows.zip`: это та же папка Дана, её достаточно распаковать и запускать `dan.exe` из неё.

Удалить Дан можно, как обычную программу: «Параметры» - «Приложения».

## Что нового в версии 1.2

- **Дан одной программой.** Компилятор Дана собран в `dan.exe` и больше не требует Python. Вместе с ним поставляется компилятор C zig, поэтому отдельный компилятор (WinLibs, MinGW) тоже не нужен. Если в системе уже есть gcc или clang, Дан использует их.
- **Установщик на русском** с ярлыками в меню «Пуск», командой `dan` в командной строке и запуском программ двойным щелчком.
- **Справочник и описание языка** входят в поставку в виде страниц, которые открываются в браузере.
- **Точность.** Кубический корень из точного куба (`корень(27.0, 3)`) всегда даёт ровно 3.0, каким бы компилятором C ни была собрана программа.
- Каждый выпуск проверяется на GitHub: установщик ставится на чистую Windows, где нет ни Python, ни компилятора C, и собирает и выполняет все программы каталога.

Программы, написанные для версий 1.0 и 1.1, работают в версии 1.2 без изменений.

## Файлы

- `dan-1.2-setup.exe` - установщик для Windows (рекомендуется);
- `dan-1.2-windows.zip` - Дан без установки;
- `install_windows.ps1` - установка для разработки самого Дана (с исходным кодом, Python и тестами);
- `dan-language-1.0.0.vsix` - расширение для редактора VS Code.
