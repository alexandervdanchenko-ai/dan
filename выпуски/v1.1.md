Дан - язык программирования, на котором программы пишутся по-русски и собираются в обычные исполняемые файлы.

## Установка в Windows

Скачайте файл `install_windows.ps1` (ниже, в разделе «Assets»), откройте окно PowerShell в папке, куда он сохранён (обычно «Загрузки»), и выполните:

```
powershell -ExecutionPolicy Bypass -File install_windows.ps1
```

Сценарий сам установит Python, компилятор C и Git, загрузит Дан и проверит его работу. Если на компьютере есть диск D, Дан ставится в `D:\проекты\Дан`, иначе - в папку `проекты\Дан` в папке пользователя.

## Что нового в версии 1.1

**Документы и почта**
- модули `word` и `excel`: создание и чтение документов `.docx` и книг `.xlsx`, заполнение шаблонов Word полями `{{поле}}`;
- модуль `csv` с определением разделителя и записью для Excel;
- модуль `pdf`: создание документов PDF с русским текстом, таблицами и номерами страниц, извлечение текста из PDF;
- модуль `xml`, встроенные архивы zip в памяти;
- модуль `почта`: отправка писем с вложениями, получение и разбор писем, папки почтового ящика.

**Окна во всех системах**
- в Windows - окна системы, в Linux и macOS - окно программы открывается в браузере.

**Совместимость и надёжность**
- устаревшие функции не удаляются внезапно: компилятор предупреждает о них заранее;
- новая функция `файлы_архива`: повреждённый архив даёт ошибку значением, а не останавливает программу; `word.из_байтов` и `excel.из_байтов` используют её;
- исправлены ошибки, найденные проверкой безопасности и фаззингом: чтение памяти за концом строки у текста с неполной буквой UTF-8, ошибки чтения повреждённых PDF, утечка памяти при разборе писем, зависание на подделанных зашифрованных данных;
- сборка в Windows программ с русскими именами файлов при любом языке системы, поддержка новых компиляторов gcc 14 и 15.

**Проверка каждого изменения**
- все тесты выполняются в Windows, Linux (x86-64 и ARM) и macOS;
- установка в Windows проверяется на чистой системе по этой инструкции;
- разборщики форматов проверяются фаззингом (libFuzzer с санитайзерами).

Программы, написанные для версии 1.0, работают в версии 1.1 без изменений.

## Файлы

- `install_windows.ps1` - установка в Windows (в репозитории этот файл называется `установить_windows.ps1`);
- `dan-language-1.0.0.vsix` - расширение для редактора VS Code (подсветка, подсказки, проверка ошибок при наборе).
