Дан - язык программирования, на котором программы пишутся по-русски и собираются в обычные исполняемые файлы.

## Установка в Windows

Скачайте ниже, в разделе «Assets», файл `dan-1.12-setup.exe` и запустите его. Права администратора не нужны. Python, компилятор C и другие программы ставить не нужно: всё необходимое уже внутри установщика. Если Дан уже установлен, установите эту версию поверх него (или выполните `dan обновить`).

В Linux и macOS Дан собирается из исходного кода тремя командами - они в README, в разделе «Установка в Linux и macOS».

## Главное

**Чтение запроса на AMD Zen 5 вровень с llama.cpp.** Веса для пакета токенов раскладываются по 16 строк под 512-битные ядра AVX-512 VNNI. Чтение запроса моделью, доля скорости llama.cpp b12190, AMD EPYC 9V45 (Zen 5), 4 потока:

| Модель | 1.11 | 1.12 |
|---|---|---|
| Mistral 7B Q2_K | 0,58-0,65 | 1,00 |
| Mistral 7B Q3_K_M | 0,58-0,65 | 1,06-1,09 |
| Mistral 7B Q4_K_M | 0,58-0,65 | 1,23 |
| Qwen2.5 0.5B Q8_0 | - | 1,04-1,10 |
| Qwen2.5 1.5B Q3_K_M | - | 0,81-0,97 |

Порождение ответа не изменилось. Чтение запроса Qwen2.5 1.5B IQ4_XS пока 0,56-0,74 - задача следующих выпусков.

**Слабая машина x86.** Перевод вектора в 8 бит перед умножением на веса выполняется командами SSE2 (доля этого шага во времени - 0,2-0,3% вместо около 5%). Недоумение IQ4_XS отличается от llama.cpp на 0,35% - это разница округлений, а не ошибка разворачивания весов (разбор - в `замеры/результаты.md`, раздел «Поток 26В»).

**Windows.** Исправлено падение векторных ядер, если среду собрать компилятором gcc MinGW 15 с `-O3`.

Ответы моделей побитно те же, что прежде. Цифры и способ замера - в `замеры/результаты.md` (разделы «Поток 26А» и «Поток 26В»).

## Новое в языке

- Векторная функция `swiglu(з, в)` - з / (1 + e^(-з)) · в поэлементно для массивов `дроб32` и `дроб` (раздел 7.7 `spec.md`); её можно вызывать в шаге `параллельно для`.
- В шаге `параллельно для` можно записывать в свой элемент массива поля общей записи: `н.р[к] = х`, `м.кэш.ключи[к][1] = х`, блок `н.р[к * ш..к * ш + ш - 1] = х`. Запись в чужой элемент - понятный отказ, новый код Д0344 (раздел 12.11).
- Модуль `нейро` пополняет кэш ключей и значений прямо в шаге `параллельно для`.

Программы, написанные для версий 1.0-1.11, работают в версии 1.12 без изменений.

## Файлы

- `dan-1.12-setup.exe` - установщик для Windows (рекомендуется);
- `dan-1.12-windows.zip` - Дан без установки;
- `install_windows.ps1` - установка для разработки самого Дана (с исходным кодом, Python и тестами);
- `dan-language-1.0.0.vsix` - расширение для редактора VS Code;
- `llama-b12190-linux-x64.zip`, `llama-b12190-linux-arm64.zip`, `llama-b12190-macos-arm64.zip`, `llama-b12190-windows-x64.zip` - библиотека llama.cpp для модуля `модели` (ставится командой `dan модели установить`; в установщике для Windows уже есть);
- `SHA256SUMS.txt` - контрольные суммы файлов.
