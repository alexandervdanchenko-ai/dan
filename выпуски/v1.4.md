Дан - язык программирования, на котором программы пишутся по-русски и собираются в обычные исполняемые файлы.

## Установка в Windows

Скачайте ниже, в разделе «Assets», файл `dan-1.4-setup.exe` и запустите его. Права администратора не нужны. Python, компилятор C и другие программы ставить не нужно: всё необходимое уже внутри установщика.

После установки в меню «Пуск» появится папка «Дан»:
- **Редактор Дан** - набрать программу и нажать «Запустить»;
- **Учебник «Дан с нуля»** - для тех, кто никогда не программировал;
- **Справочник языка** и **Примеры программ**;
- **Дан - командная строка** - команды `dan запустить`, `dan собрать`, `dan задачи`.

Программу `.dan` можно запустить двойным щелчком, а команда «Изменить» в её меню открывает редактор. Если устанавливать нельзя, подойдёт `dan-1.4-windows.zip`: его достаточно распаковать.

## Что нового

**Версия 1.4: тесты, документация, скорость**
- Встроенные тесты: блок `тест "название" { ... }` прямо в файле программы, команда `dan тестировать`, утверждения `утвердить` и `утвердить_равно`.
- Документация из комментариев `///`: `dan документация` создаёт страницы с поиском, `dan документация --проверить` выполняет примеры из описаний как тесты. Редактор показывает описание при наведении.
- `dan профиль программа.dan`: сколько времени заняла каждая функция и сколько раз она вызвана, в том числе в параллельных задачах.
- `dan обновить`: новая версия ставится одной командой, скачанный файл сверяется с контрольной суммой; каналы «стабильный» и «пробный».
- `dan песочница`: страница в браузере, где программу можно написать и сразу выполнить, с примерами; в Windows - и из меню «Пуск».
- Собранные программы запоминаются: повторный запуск той же программы занимает сотые доли секунды.
- Быстрее: строки и словари в полтора раза, JSON в 1,7 раза, CSV в 2,8 раза.
- Пакеты: `пакеты установить --заморожено` не меняет замок, поставленные пакеты ставятся повторно без сети.
- Одинаковые результаты на всех компьютерах: «не число» и бесконечность выводятся как `nan` и `inf`, дробные вычисления и корни многочленов дают одни и те же цифры на x86 и ARM при любом компиляторе C.

**Версия 1.3: обучение и русская раскладка**
- Учебник «Дан с нуля» из 21 главы: от первой программы через игру «Угадай число», числа, условия, повторение, строки, списки, функции, ошибки, свои типы и словари к файлам, модулям, сквозному проекту «Учёт расходов», документам Word, окнам и сети. Каждая программа книги проверяется тестами: она собирается и печатает ровно то, что показано в тексте.
- Задачник из 12 задач с автоматической проверкой: `dan задачи` копирует задачи в папку «задачи», `dan задача 3` проверяет решение и показывает, на каких данных оно ошибается.
- Программу можно набрать целиком в русской раскладке, не переключаясь на латинскую: блоки отступом после двоеточия, `оценки№0` вместо `оценки[0]`, списки и словари в круглых скобках, сравнения словами `больше`, `меньше`, `не больше`, `не меньше`. Прежняя запись тоже работает, их можно смешивать. Об этом глава 21 учебника.
- Редактор для Windows, написанный на самом Дане: «Проверить», «Запустить», «Собрать .exe», учебник и справочник одной кнопкой.

**Версия 1.2: Дан одной программой**
- `dan.exe` больше не требует Python, а компилятор C zig поставляется вместе с ним. Если в системе есть gcc или clang, Дан использует их.
- Установщик на русском: ярлыки, команда `dan` в командной строке, запуск программ двойным щелчком, удаление через «Параметры».
- Кубический корень из точного куба всегда ровный при любом компиляторе C.
- Файлы `SECURITY.md`, `CHANGELOG.md`, формы для сообщений об ошибках и предложений, перечень исключений из гарантии совместимости.

Каждый выпуск проверяется на GitHub: установщик ставится на чистую Windows, где нет ни Python, ни компилятора C, и собирает и выполняет все программы каталога. Программы, написанные для версий 1.0-1.3, работают в версии 1.4 без изменений.

## Файлы

- `dan-1.4-setup.exe` - установщик для Windows (рекомендуется);
- `dan-1.4-windows.zip` - Дан без установки;
- `install_windows.ps1` - установка для разработки самого Дана (с исходным кодом, Python и тестами);
- `dan-language-1.0.0.vsix` - расширение для редактора VS Code;
- `SHA256SUMS.txt` - контрольные суммы файлов.
