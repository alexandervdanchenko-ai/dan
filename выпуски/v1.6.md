Дан - язык программирования, на котором программы пишутся по-русски и собираются в обычные исполняемые файлы.

## Установка в Windows

Скачайте ниже, в разделе «Assets», файл `dan-1.6-setup.exe` и запустите его. Права администратора не нужны. Python, компилятор C и другие программы ставить не нужно: всё необходимое уже внутри установщика.

После установки в меню «Пуск» появится папка «Дан»:
- **Редактор Дан** - набрать программу и нажать «Запустить»;
- **Учебник «Дан с нуля»** - для тех, кто никогда не программировал;
- **Справочник языка** и **Примеры программ**;
- **Дан - командная строка** - команды `dan запустить`, `dan собрать`, `dan задачи`.

Программу `.dan` можно запустить двойным щелчком, а команда «Изменить» в её меню открывает редактор. Если устанавливать нельзя, подойдёт `dan-1.6-windows.zip`: его достаточно распаковать.

## Что нового

**Версия 1.6: локальные языковые модели**

- Модуль `модели`: программа на Дане загружает модель в формате GGUF и получает ответ целиком, по частям (по словам, как в чате) или по списку сообщений с шаблоном самой модели. При температуре 0 ответ повторяется слово в слово. Работа идёт через библиотеку llama.cpp; модуль медленнее самой llama.cpp на 1-2%.
- Библиотека llama.cpp входит в установщик для Windows; для Linux и macOS она лежит на странице выпуска, а `dan модели установить` ставит её и сверяет контрольную сумму, `dan модели проверить` показывает, что найдено и какой вариант выбран для процессора. Видеокарта не нужна.
- Пример `примеры/модель_чат.dan`: разговор с моделью в консоли.
- Эталон скорости памяти (`замеры/память`): по нему проверяется главная цель - сколько слов в секунду позволяет память компьютера для модели заданного размера.
- Надёжность: шифрование в zip-архивах больше не зависит по времени от ключа (на процессорах с аппаратным AES оно к тому же в десятки раз быстрее), шифрование сверено с 1051 тестовым вектором Wycheproof, а при шифровании больше 256 ГБ за раз теперь ошибка вместо повтора шифра; анализатор gcc проверяет код среды при каждом изменении.
- Исправлено: цикл по полному диапазону целых не выполнялся; `dan собрать` затирал лежащий рядом чужой файл `.c`; в Linux программы с модулем `данные` не собирались компилятором clang.

**Версия 1.5: быстрые вычисления на обычном компьютере**

Главная цель ближайших выпусков - запуск локальных языковых моделей на компьютере без видеокарты (план - в `ROADMAP.md`). Версия 1.5 закладывает для этого основу.

- Плотные массивы чисел `массив<дроб32>`, `массив<дроб16>`, `массив<цел8>` и другие: числа лежат подряд, как в C. `массив<дроб32>` работает с той же скоростью, что C, и занимает втрое меньше памяти, чем список.
- Массив из файла `массив_из_файла(...)`: большой файл (например, веса модели) открывается сразу, без чтения в память заранее. Упакованные `массив<цел4>` и `массив<цел2>` для сжатых весов. Массивы передаются в функции C без копии.
- Векторные вычисления: скалярное произведение, матрица на вектор и на матрицу, софтмакс, нормировки, веса в 8 битах (формат Q8_0). Вариант для процессора (AVX2, AVX-512, NEON) выбирается сам, работа делится на все ядра; на 4 ядрах матрица на вектор и на матрицу считается в 3,7-4 раза быстрее, чем на одном. Результат одинаков на любом процессоре при любом числе ядер; блок `приближённо { ... }` разрешает считать быстрее ценой последних знаков.
- `параллельно для к в а..б { ... }`: шаги цикла выполняются на всех ядрах (на двух ядрах - вдвое быстрее). Компилятор при сборке доказывает, что шаги не мешают друг другу; если доказать не удалось, он объясняет почему (коды Д0308-Д0317) и что исправить.
- Компилятор сам убирает проверки границ и переполнения там, где доказал, что они не сработают: работа со списками чисел в цикле - до 4,4 раза быстрее. Поведение программ не меняется.
- Компилятор Дана написан на самом Дане и собирается из файла на C одним компилятором C, без Python.
- Если в самом компиляторе случается внутренняя ошибка, выводится короткое русское сообщение, а подробности записываются в файл для сообщения об ошибке.

Каждый выпуск проверяется на GitHub: установщик ставится на чистую Windows, где нет ни Python, ни компилятора C, и собирает и выполняет все программы каталога. Программы, написанные для версий 1.0-1.5, работают в версии 1.6 без изменений.

## Файлы

- `dan-1.6-setup.exe` - установщик для Windows (рекомендуется);
- `dan-1.6-windows.zip` - Дан без установки;
- `install_windows.ps1` - установка для разработки самого Дана (с исходным кодом, Python и тестами);
- `dan-language-1.0.0.vsix` - расширение для редактора VS Code;
- `llama-b12190-linux-x64.zip`, `llama-b12190-linux-arm64.zip`, `llama-b12190-macos-arm64.zip`, `llama-b12190-windows-x64.zip` - библиотека llama.cpp для модуля `модели` (ставится командой `dan модели установить`; в установщике для Windows уже есть);
- `SHA256SUMS.txt` - контрольные суммы файлов.
