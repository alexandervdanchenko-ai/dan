Дан - язык программирования, на котором программы пишутся по-русски и собираются в обычные исполняемые файлы.

## Установка в Windows

Скачайте ниже, в разделе «Assets», файл `dan-1.5-setup.exe` и запустите его. Права администратора не нужны. Python, компилятор C и другие программы ставить не нужно: всё необходимое уже внутри установщика.

После установки в меню «Пуск» появится папка «Дан»:
- **Редактор Дан** - набрать программу и нажать «Запустить»;
- **Учебник «Дан с нуля»** - для тех, кто никогда не программировал;
- **Справочник языка** и **Примеры программ**;
- **Дан - командная строка** - команды `dan запустить`, `dan собрать`, `dan задачи`.

Программу `.dan` можно запустить двойным щелчком, а команда «Изменить» в её меню открывает редактор. Если устанавливать нельзя, подойдёт `dan-1.5-windows.zip`: его достаточно распаковать.

## Что нового

**Версия 1.5: быстрые вычисления на обычном компьютере**

Главная цель ближайших выпусков - запуск локальных языковых моделей на компьютере без видеокарты (план - в `ROADMAP.md`). Версия 1.5 закладывает для этого основу.

- Плотные массивы чисел `массив<дроб32>`, `массив<дроб16>`, `массив<цел8>` и другие: числа лежат подряд, как в C. `массив<дроб32>` работает с той же скоростью, что C, и занимает втрое меньше памяти, чем список.
- Массив из файла `массив_из_файла(...)`: большой файл (например, веса модели) открывается сразу, без чтения в память заранее. Упакованные `массив<цел4>` и `массив<цел2>` для сжатых весов. Массивы передаются в функции C без копии.
- Векторные вычисления: скалярное произведение, матрица на вектор и на матрицу, софтмакс, нормировки, веса в 8 битах (формат Q8_0). Вариант для процессора (AVX2, AVX-512, NEON) выбирается сам, работа делится на все ядра; на 4 ядрах матрица на вектор и на матрицу считается в 3,7-4 раза быстрее, чем на одном. Результат одинаков на любом процессоре при любом числе ядер; блок `приближённо { ... }` разрешает считать быстрее ценой последних знаков.
- `параллельно для к в а..б { ... }`: шаги цикла выполняются на всех ядрах (на двух ядрах - вдвое быстрее). Компилятор при сборке доказывает, что шаги не мешают друг другу; если доказать не удалось, он объясняет почему (коды Д0308-Д0317) и что исправить.
- Компилятор сам убирает проверки границ и переполнения там, где доказал, что они не сработают: работа со списками чисел в цикле - до 4,4 раза быстрее. Поведение программ не меняется.
- Компилятор Дана написан на самом Дане и собирается из файла на C одним компилятором C, без Python.
- Если в самом компиляторе случается внутренняя ошибка, выводится короткое русское сообщение, а подробности записываются в файл для сообщения об ошибке.

**Версия 1.4: тесты, документация, скорость**
- Встроенные тесты: блок `тест "название" { ... }` прямо в файле программы, команда `dan тестировать`, утверждения `утвердить` и `утвердить_равно`.
- Документация из комментариев `///`: `dan документация` создаёт страницы с поиском, `dan документация --проверить` выполняет примеры из описаний как тесты. Редактор показывает описание при наведении.
- `dan профиль программа.dan`: сколько времени заняла каждая функция и сколько раз она вызвана, в том числе в параллельных задачах.
- `dan обновить`: новая версия ставится одной командой, скачанный файл сверяется с контрольной суммой; каналы «стабильный» и «пробный».
- `dan песочница`: страница в браузере, где программу можно написать и сразу выполнить, с примерами; в Windows - и из меню «Пуск».
- Собранные программы запоминаются: повторный запуск той же программы занимает сотые доли секунды.
- Быстрее: строки и словари в полтора раза, JSON в 1,7 раза, CSV в 2,8 раза.
- Пакеты: `пакеты установить --заморожено` не меняет замок, поставленные пакеты ставятся повторно без сети.
- Одинаковые результаты на всех компьютерах: «не число» и бесконечность выводятся как `nan` и `inf`, дробные вычисления и корни многочленов дают одни и те же цифры на x86 и ARM при любом компиляторе C.

Каждый выпуск проверяется на GitHub: установщик ставится на чистую Windows, где нет ни Python, ни компилятора C, и собирает и выполняет все программы каталога. Программы, написанные для версий 1.0-1.4, работают в версии 1.5 без изменений.

## Файлы

- `dan-1.5-setup.exe` - установщик для Windows (рекомендуется);
- `dan-1.5-windows.zip` - Дан без установки;
- `install_windows.ps1` - установка для разработки самого Дана (с исходным кодом, Python и тестами);
- `dan-language-1.0.0.vsix` - расширение для редактора VS Code;
- `SHA256SUMS.txt` - контрольные суммы файлов.
