Дан - язык программирования, на котором программы пишутся по-русски и собираются в обычные исполняемые файлы.

## Установка в Windows

Скачайте ниже, в разделе «Assets», файл `dan-1.9-setup.exe` и запустите его. Права администратора не нужны. Python, компилятор C и другие программы ставить не нужно: всё необходимое уже внутри установщика. Если Дан уже установлен, установите эту версию поверх него (или выполните `dan обновить`).

В Linux и macOS Дан собирается из исходного кода тремя командами - они в README, в разделе «Установка в Linux и macOS».

## Главное

**Чтение запроса почти как у llama.cpp.** Модуль `нейро` читает присланный модели текст новыми ядрами: несколько строк сжатых весов умножаются на несколько токенов за один проход (AVX-512 VNNI, AVX2 и ARM с dotprod). Mistral 7B Q4_K_M, 4 потока: AMD EPYC 9V74 - 22,6 токена в секунду (llama.cpp 23,1, доля 0,98; в 1.8 было 12,6), AMD EPYC 7763 - 0,97 скорости llama.cpp, ARM Neoverse N2 - 18,8 (0,88; было 11,6). Ответы модели побитно те же, порождение не замедлилось. На новейших процессорах (Intel Xeon 6, AMD Zen 5) Дан пока в 2-3 раза медленнее llama.cpp - это задача следующего выпуска. Цифры и способ замера - в `замеры/результаты.md`.

**Спекулятивная генерация.** `м.ответ_с_черновиком(черновик, запрос, выборка)` предлагает несколько токенов маленькой моделью и проверяет их большой одним проходом. При жадной выборке ответ побайтно тот же, что без черновика, при выборке с температурой - то же распределение ответов. Модель-черновик проверяется на совместимость словаря (`м.проверить_черновик`). На процессоре ускорение пока скромное: до 1,17 раза на коде (Qwen2.5 7B с черновиком 0.5B), на обычном тексте черновик не помогает - так же и у llama.cpp на процессоре.

## Новое в языке

- Запись части: `м[а..б] = х` - для массива одно копирование памяти, перекрытие частей допустимо, длины проверяются.
- `склеить(а, б)` - новый массив или список из двух.
- Сводка в `параллельно для`: `параллельно для к в 0..н - 1 сводка сумма { сумма += ... }`. Порядок сложения постоянный, итог побитно одинаков при любом числе потоков.
- В шаге `параллельно для` можно читать поля общих записей и передавать части массивов (`сам.веса[а..б]`) во встроенные векторные функции без копии; блок шага записывается одной записью части.
- Новые сообщения Д0333-Д0341 с объяснением в `dan объяснить`; на `а + б` для списков и массивов компилятор подсказывает `склеить`.

Программы, написанные для версий 1.0-1.8, работают в версии 1.9 без изменений.

## Файлы

- `dan-1.9-setup.exe` - установщик для Windows (рекомендуется);
- `dan-1.9-windows.zip` - Дан без установки;
- `install_windows.ps1` - установка для разработки самого Дана (с исходным кодом, Python и тестами);
- `dan-language-1.0.0.vsix` - расширение для редактора VS Code;
- `llama-b12190-linux-x64.zip`, `llama-b12190-linux-arm64.zip`, `llama-b12190-macos-arm64.zip`, `llama-b12190-windows-x64.zip` - библиотека llama.cpp для модуля `модели` (ставится командой `dan модели установить`; в установщике для Windows уже есть);
- `SHA256SUMS.txt` - контрольные суммы файлов.
