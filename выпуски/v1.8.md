Дан - язык программирования, на котором программы пишутся по-русски и собираются в обычные исполняемые файлы.

## Установка в Windows

Скачайте ниже, в разделе «Assets», файл `dan-1.8-setup.exe` и запустите его. Права администратора не нужны. Python, компилятор C и другие программы ставить не нужно: всё необходимое уже внутри установщика. Если Дан уже установлен, установите эту версию поверх него (или выполните `dan обновить`).

В Linux и macOS Дан собирается из исходного кода тремя командами - они в README, в разделе «Установка в Linux и macOS».

## Главное

**Собственный движок моделей быстрее.** Модуль `нейро` читает присланный модели текст в 1,6-1,75 раза быстрее, чем в 1.7: сжатые веса теперь умножаются сразу на все токены запроса новыми ядрами `матвеки_*`. Веса Q5_0, Q4_1 и Q5_1 считаются прямо из файла, без разворачивания. Маленькие модели ближе к пределу, который задаёт скорость памяти: головы внимания и часть вычислений слоя идут на всех ядрах, а пул потоков не засыпает между короткими работами. На машине GitHub (AMD EPYC 9V74, 4 потока) доля предела: TinyLlama Q4_K_M - 0,92 (было 0,73), Qwen2.5 0.5B Q4_K_M - 0,83 (было 0,65), Mistral 7B Q4_K_M - 0,92. Ответы модели не зависят от числа потоков. Чтение запроса на 7B пока в 1,8 раза медленнее llama.cpp. Цифры и способ замера - в `замеры/результаты.md`.

**Понятнее сообщения.**
- Пустой обработчик ошибки (`если ошибка о = ф() { }`) больше не проходит молча: компилятор предупреждает (код Д0331) и подсказывает, как обработать ошибку или передать её дальше. Если ошибка пропускается намеренно, достаточно написать в блоке комментарий с причиной. Программа по-прежнему собирается.
- Строка, начатая знаком (`+ 2` после `пусть а = 1`), получает подсказку: при переносе знак ставится в конце предыдущей строки (код Д0332).
- Компилятор находит свою папку сам - рядом с исполняемым файлом или папкой выше (так у `semya/dan`). Если папки нет, он говорит об этом и предлагает запустить его из папки проекта или задать `DAN_HOME`, а не печатает внутреннюю «Ошибку выполнения в строке 303».

## Новое в языке и скорости

- Анализ диапазонов разбирает циклы `пока и < н { ... и += шаг }`: проверки границ и переполнения, которые доказуемо не сработают, снимаются (решето Эратосфена - в 1,13 раза медленнее C вместо 1,24). Так же снимаются проверки в шагах `параллельно для`.
- В шаге `параллельно для` можно записывать блок общего массива `р[к * ш + j]`.
- Ядра `матвеки_q4_0`, `матвеки_q4k`, `матвеки_q5k`, `матвеки_q6k`, `матвеки_q5_0`, `матвеки_q4_1`, `матвеки_q5_1`, `матвеки_q8` и ядра для весов Q5_0, Q4_1, Q5_1 (`матвек_*`, `из_*`).
- Модули библиотеки могут использовать `параллельно для` и другие возможности версий 1.5 и новее.

Программы, написанные для версий 1.0-1.7, работают в версии 1.8 без изменений; новое предупреждение не мешает сборке.

## Файлы

- `dan-1.8-setup.exe` - установщик для Windows (рекомендуется);
- `dan-1.8-windows.zip` - Дан без установки;
- `install_windows.ps1` - установка для разработки самого Дана (с исходным кодом, Python и тестами);
- `dan-language-1.0.0.vsix` - расширение для редактора VS Code;
- `llama-b12190-linux-x64.zip`, `llama-b12190-linux-arm64.zip`, `llama-b12190-macos-arm64.zip`, `llama-b12190-windows-x64.zip` - библиотека llama.cpp для модуля `модели` (ставится командой `dan модели установить`; в установщике для Windows уже есть);
- `SHA256SUMS.txt` - контрольные суммы файлов.
