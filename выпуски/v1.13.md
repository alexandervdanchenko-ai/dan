Дан - язык программирования, на котором программы пишутся по-русски и собираются в обычные исполняемые файлы.

## Установка в Windows

Скачайте ниже, в разделе «Assets», файл `dan-1.13-setup.exe` и запустите его. Права администратора не нужны. Python, компилятор C и другие программы ставить не нужно: всё необходимое уже внутри установщика. Если Дан уже установлен, установите эту версию поверх него (или выполните `dan обновить`).

В Linux и macOS Дан собирается из исходного кода тремя командами - они в README, в разделе «Установка в Linux и macOS».

## Главное

**Программы общего назначения.** Новые модули стандартной библиотеки, написанные на Дане:

- `вебсервер` - сервер HTTP/1.1: обработчик - обычная функция, параметры запроса, ответы текстом, HTML и JSON, соединения обслуживают несколько задач; 33 000 запросов в секунду на 2 ядрах против 2 300 у `http.server` Python;
- `командная_строка` - разбор параметров с проверкой и справкой;
- `журнал` - строка на событие с временем и уровнем, обычным текстом или JSON;
- `настройки` - файлы TOML 1.0 и YAML (сверены с tomllib и PyYAML).

**JSON прямо в свои типы.** Если устройство данных известно, текст JSON разбирается сразу в собственный тип, без дерева `json.Значение`:

```
подключить "json"
тип Заказ {
    номер "id": цел
    клиент "customer": стр
    скидка: дроб?
}
пусть заказы = json.разобрать_в(прочитать("заказы.json"), [Заказ])!
записать("копия.json", json.записать(заказы))
```

Ключ поля в JSON можно задать в объявлении типа (`номер "id": цел`), лишние ключи пропускаются, ошибка называет место в тексте и ключ поля. Это в 3,7 раза быстрее разбора в дерево и в 10 раз быстрее Python с `dataclasses`.

**Общие задачи быстрее.** Отношение времени Дана ко времени программы на C (`замеры/результаты.md`, машина разработки):

| Задача | 1.12 | 1.13 |
|---|---|---|
| сжатие gzip 20 МБ | 4,43 | 1,36-1,46 |
| таблицы CSV | 2,33 | 1,17-1,27 |
| обмен JSON (дерево `json.Значение`) | 2,87 | 1,91-1,99 |
| записи JSON в свои типы (новая задача) | - | 1,4 |
| решето | 1,11 | 1,02 |

Сжатие получило уровни 1-9 (по умолчанию 6, как в zlib; уровень 9 даёт прежние байты) и CRC-32 командами процессора; запись CSV и разбор и запись дерева JSON выполняет код на C; склейка строк цепочкой и `соединить` собирают итог одним выделением памяти.

**Хеши и коды подлинности** своими силами: SHA-224, SHA-256, SHA-384, SHA-512, SHA3-256, SHA3-512, BLAKE3, HMAC-SHA256 и HMAC-SHA512, HKDF, PBKDF2, сравнение за постоянное время; SHA-256 - командами SHA-NI, где они есть. Проверены эталонными векторами NIST и RFC.

**Математика.** Опись того, что есть, с полнотой каждой функции (`математика/охват.md`); полное разложение многочленов на неприводимые множители над рациональными числами (`разложить(х^4 + 3*х^2 + 2)` - «(х² + 1)(х² + 2)»); корни многочленов высокой степени; все ставки доходности `все_ставки_доходности`; `простое` и `простые_множители` для 64-битных чисел - за миллисекунды вместо секунд.

**Редактор.** Сервер языка показывает места имени, переименовывает и предлагает быстрые исправления (опечатки и привычки Python) - в VS Code по Ctrl+.

**Показательные программы** (папка `показательные`): бот для Telegram, REST-сервис с SQLite, сводка документов Word и Excel, поиск дубликатов файлов.

## Новое в языке

- `json.разобрать_в(текст, Тип)` и `json.записать` собственных типов, списков и словарей; ключ поля JSON в объявлении типа: `номер "id": цел` (разделы 8.1, 11.20 `spec.md`).
- Встроенные `случайные_байты`, `uuid`, `uuid_по_времени`, `записать_csv`, хеши и коды подлинности, `равны_за_постоянное_время`, `все_ставки_доходности`; `сжать_gzip(д, уровень)`.
- Исправлено: программы, в которых `компл`, `длинное` или `дата` встречаются только внутри списка или словаря (`комплексные_корни(1, 0, 4)`, пустой `[дата]`), собираются компилятором на Дане.

Программы, написанные для версий 1.0-1.12, работают в версии 1.13 без изменений.

## Файлы

- `dan-1.13-setup.exe` - установщик для Windows (рекомендуется);
- `dan-1.13-windows.zip` - Дан без установки;
- `install_windows.ps1` - установка для разработки самого Дана (с исходным кодом, Python и тестами);
- `dan-language-1.0.0.vsix` - расширение для редактора VS Code;
- `llama-b12190-linux-x64.zip`, `llama-b12190-linux-arm64.zip`, `llama-b12190-macos-arm64.zip`, `llama-b12190-windows-x64.zip` - библиотека llama.cpp для модуля `модели` (ставится командой `dan модели установить`; в установщике для Windows уже есть);
- `SHA256SUMS.txt` - контрольные суммы файлов.
