# Глава 20. Готовая программа и что дальше

## Программа для других людей

```
dan собрать программа.dan
```

создаёт `программа.exe`. Ему не нужен Дан: файл можно переслать или положить на флешку. Чтобы файл был меньше, добавьте `--малый`.

Программе можно передавать значения при запуске:

{{листинг 20/аргументы}}

```
dan запустить аргументы.dan Анна Борис
```

## Что дальше

- Решайте задачи задачника: `dan задачи` покажет список, `dan задача 1` проверит ваше решение первой задачи.
- В справочнике (меню «Пуск» - «Дан» - «Справочник языка») перечислена вся стандартная библиотека: математика, даты, регулярные выражения, JSON, базы данных SQLite.
- В папке «Документы\Дан\примеры» лежат готовые программы: открывайте, запускайте, меняйте.
- `dan отладка программа.dan` выполняет программу по шагам и показывает значения переменных.
- `dan объяснить программа.dan:12` объясняет по-русски, что делает строка 12 программы: что в ней объявляется и вычисляется и какого типа получаются значения. Это помогает разобраться в чужой программе.
