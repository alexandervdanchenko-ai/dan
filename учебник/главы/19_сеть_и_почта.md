# Глава 19. Сеть и почта

{{листинг 19/сеть}}

`http.получить(адрес)` загружает страницу; результат - ответ или ошибка, если связи нет. Ответ с кодом 404 - не ошибка: сервер ответил, что страницы нет.

Модуль `почта` отправляет письма с вложениями и получает письма из ящика:

```
подключить "почта"
пусть ящик = почта.Ящик("ivanov@yandex.ru", "пароль приложения")
почта.отправить(ящик, почта.Письмо(["petrov@mail.ru"], "Отчёт", "Отчёт во вложении.", вложения = ["отчёт.pdf"]))!
```

Для почтовых ящиков Яндекса и Mail.ru нужен не обычный пароль, а «пароль приложения», который создаётся в настройках ящика.

Программам этой главы нужна связь с интернетом, поэтому в проверках учебника они только собираются.
