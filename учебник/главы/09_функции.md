# Глава 9. Функции

Функция - это часть программы с именем, которую можно вызывать много раз.

{{листинг 09/функции}}

- `функ площадь_комнаты(длина: дроб, ширина: дроб) -> дроб` - функция с двумя параметрами. У каждого параметра указан вид значения, а после `->` - вид результата.
- `вернуть` - закончить функцию и отдать результат.
- Функция без результата пишется без `->`.

Функция видит только свои параметры. Переменные, созданные снаружи, ей не видны: всё нужное передаётся параметрами. Так по заголовку функции всегда понятно, от чего зависит её результат.

Аргументы можно называть по имени, тогда порядок не важен: `площадь_комнаты(ширина = 3.2, длина = 4.5)`.
