# Глава 13. Перечисления и выбор

Иногда значение бывает одного из нескольких видов, и у каждого вида свои данные. Например, платёж наличными, картой или бесплатный.

{{листинг 13/выбор}}

- В описании типа перечислены варианты: `Наличные(сумма: цел)`, `Карта(...)`, `Бесплатно`.
- `выбор п { ... }` разбирает значение: для каждого варианта своя ветвь, а данные варианта получают имена (`Наличные(с)`).
- Если какой-то вариант не разобран и нет ветви `иначе`, программа не соберётся. Когда в тип добавят новый вариант, Дан покажет все места, где его нужно учесть.

`выбор` работает и с числами и строками: ветви `5`, `4`, а для остальных - `иначе`.
