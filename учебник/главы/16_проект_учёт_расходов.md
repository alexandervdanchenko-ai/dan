# Глава 16. Проект: учёт расходов

Соберём вместе то, что уже знаем. Программа читает таблицу расходов в формате CSV (её можно сохранить из Excel), считает итог по каждой статье и долю в процентах и сохраняет отчёт, который откроется в Excel.

{{листинг 16/расходы}}

Что здесь используется:

- `подключить "csv"` - модуль стандартной библиотеки для таблиц CSV; `csv.разобрать` сам определяет разделитель (`;` или `,`);
- `csv.разобрать(...)!` - если файл повреждён, программа остановится с понятным сообщением;
- `строки[1..строки.длина - 1]` - все строки, кроме шапки;
- словарь `по_статьям` копит суммы;
- `сколько_процентов`, `округлить` - математика из стандартной библиотеки;
- `сумма_цифрами(рац(сумма, 1))` - сумма в привычной записи с пробелами между разрядами;
- `csv.записать_для_excel` записывает таблицу так, что Excel открывает её с русскими буквами и столбцами.

Попробуйте изменить программу: читать данные из настоящего файла, выгруженного из банка, и добавить итог по месяцам.
