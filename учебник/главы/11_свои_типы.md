# Глава 11. Собственные типы

Когда у значения несколько свойств, удобно описать свой тип.

{{листинг 11/типы}}

- `тип Сотрудник { ... }` описывает поля и их виды. У поля может быть значение по умолчанию: `стаж_лет: цел = 0`.
- `Сотрудник("Иванов", "инженер", 80000, стаж_лет = 7)` создаёт значение. Поля можно называть по имени.
- `иванов.оклад` - обращение к полю; изменить поле можно, если значение создано через `перем`.
- `функ Сотрудник.надбавка()` - метод: функция, которая вызывается через точку. Внутри метода само значение называется `сам`.

`вывод` печатает значение целиком со всеми полями - это удобно при поиске ошибок.
