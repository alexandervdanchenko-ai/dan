# Глава 21. Программа без латинской раскладки

Фигурные `{ }` и квадратные `[ ]` скобки, знаки `<` и `>` есть только в латинской раскладке клавиатуры. Чтобы не переключаться, в Дане для каждой такой записи есть равнозначная, которая набирается в русской раскладке. Обе записи можно смешивать, смысл программы от этого не меняется.

Что здесь вместо латинских знаков:

- **Блок отступом.** Строка, которая оканчивается двоеточием, открывает блок, а его тело - следующие строки с бо́льшим отступом (обычно на четыре пробела). Блок кончается, когда отступ возвращается назад. Так записаны функция, цикл `для` и ветви `если`.
- **Номер элемента через `№`:** `журнал№фамилия`, `оценки№0`, `оценки№(к + 1)` - вместо `журнал[фамилия]`, `оценки[0]`, `оценки[к + 1]`.
- **Список в круглых скобках:** `(5, 4, 5)`. Список из одного элемента пишется с запятой: `(5,)`, пустой - `()`.
- **Словарь в круглых скобках со знаком `=`:** `("Иванов" = (5, 4, 5))`, пустой словарь - `(=)`.
- **Виды списков и словарей:** `(цел)` вместо `[цел]`, `(стр: цел)` вместо `{стр: цел}`.
- **Сравнения словами:** `больше`, `меньше`, `не больше` (меньше или равно), `не меньше` (больше или равно).
- **Вид результата функции** пишется сразу после скобок, без стрелки `->`: `функ средний_балл(оценки: (цел)) дроб:`.

Команда `dan формат программа.dan` выравнивает отступы в блоках по четыре пробела, не меняя записи.
