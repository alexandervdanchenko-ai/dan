# Глава 8. Списки

Список хранит много значений по порядку.

{{листинг 08/списки}}

- `[5, 4, 3, 5]` - список из четырёх чисел. Все элементы одного вида.
- `.добавить(х)` - добавить в конец, `.удалить(к)` - удалить элемент с номером `к`, `.вставить(к, х)`.
- `оценки[0]` - первый элемент. Обращение к несуществующему номеру останавливает программу с понятным сообщением, а не портит память.
- `сумма`, `среднее`, `упорядочить`, `мин`, `макс` - встроенные функции для списков чисел.
- `.отобрать(функ(о) = о == 5)` - оставить только пятёрки. `функ(о) = ...` - короткая безымянная функция: «для каждого `о` проверить, равно ли оно 5».

Пустой список требует указать вид элементов: `перем имена: [стр] = []`.

Списки в Дане ведут себя как числа: после `перем б = а` у `б` своя копия, и изменение `б` не меняет `а`.
