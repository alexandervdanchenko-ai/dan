# Глава 18. Программа с окном

{{листинг 18/окно}}

- `окна.создать(заголовок, ширина, высота)` - создать окно;
- `окно.надпись`, `окно.кнопка`, `окно.поле`, `окно.список` и другие - элементы; числа - положение и размер в точках;
- `пока пусть событие = окно.ждать()` - ждать действий человека, пока окно не закрыто;
- `выбор событие { окна.Нажатие(элемент) { ... } }` - что делать при нажатии кнопки.

В Windows программа показывает обычное окно системы. В Linux и macOS та же программа открывает окно в браузере.

Эта программа ждёт действий человека, поэтому в проверках учебника она только собирается, но не запускается.
