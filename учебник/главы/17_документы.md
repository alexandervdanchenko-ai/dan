# Глава 17. Документы Word, Excel и PDF

Дан умеет создавать и читать документы без Microsoft Office.

{{листинг 17/документ}}

- `word.создать(путь, блоки)` - создать документ из блоков: `word.заголовок`, `word.абзац`, `word.жирный`, `word.по_центру`, `word.таблица`, `word.разрыв_страницы`.
- `word.открыть(путь)` - прочитать документ; `.абзацы()`, `.таблицы()`, `.текст()`.
- `word.заполнить(шаблон, итог, {"имя": "Иванов"})` - заполнить шаблон: в документе Word заранее пишутся поля `{{имя}}`.

Так же устроены модули `excel` (книги `.xlsx`) и `pdf` (создание документов PDF с русским текстом и чтение текста из PDF). Подробности - в справочнике, раздел «Библиотека».
