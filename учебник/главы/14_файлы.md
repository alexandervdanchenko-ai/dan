# Глава 14. Файлы

{{листинг 14/файлы}}

- `записать(путь, текст)` создаёт или заменяет файл, `дописать` - добавляет в конец.
- `прочитать(путь)` возвращает весь текст файла. Окончания строк Windows приводятся к обычным.
- `существует`, `удалить_файл`, `создать_папку`, `список_файлов` - работа с файлами и папками.

Путь без папки означает файл в текущей папке - той, откуда запущена программа. Русские буквы и пробелы в именах файлов допустимы.

Для байтов (картинки, архивы) есть `прочитать_байты` и `записать(путь, байты)`; для сжатия и шифрования - `сжать`, `распаковать`, `зашифровать`, `расшифровать`.
