# Глава 6. Повторение

## Для каждого

`для` повторяет действия для каждого числа из диапазона, каждого элемента списка или каждой буквы строки.

{{листинг 06/циклы}}

`1..5` - числа от 1 до 5 включительно. Переменная `к` по очереди принимает значения 1, 2, 3, 4, 5.

## Пока

`пока` повторяет действия, пока условие верно. Во второй части примера вклад растёт на 8% в год, пока не станет больше 150 000.

Если условие никогда не станет ложным, программа будет работать бесконечно. Остановить её можно сочетанием клавиш Ctrl+C.

## Прервать и продолжить

- `прервать` - немедленно выйти из повторения;
- `продолжить` - перейти к следующему шагу, пропустив остаток текущего.
