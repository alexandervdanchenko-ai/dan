# План развития Дана

Главная цель ближайших выпусков - быстрые вычисления на обычном компьютере, вплоть до запуска локальных языковых моделей без видеокарты (4 ядра, 8 ГБ памяти).

**Цель достигнута, когда** модель 7B в формате Q4_K_M (около 4,1 ГБ весов) на таком компьютере выдаёт текст со скоростью не ниже 80% предела, который задаёт память: измеренная скорость чтения памяти, делённая на объём весов. Скорость чтения берётся не из паспорта памяти, а измеряется на той же машине эталонной программой из `замеры/`: последовательное чтение буфера размером с веса так же, как его читает движок (те же потоки, то же выравнивание). На двухканальной памяти DDR4 предел обычно 6-10 слов (токенов) в секунду.

Это главный показатель; остальные замеры служат ему или проверяют смежные свойства (скорость отдельных задач, сравнение с другими языками).

Что уже выпущено - в `CHANGELOG.md`, правила участия - в `УЧАСТИЕ.md`.

## Сделано недавно

Статический анализ кода C среды и программ (`-fanalyzer`) в каждой проверке, со списком разобранных предупреждений; `-O3` при сборке; компилятор написан на самом Дане и собирается из семени на C (`semya/dan.c`) без Python, компилятор на Python заморожен и служит эталоном.

## Направления без заданного порядка

Делаются параллельно с выпусками, по мере надобности; порядок внутри пункта тоже определяется по ходу работы.

1. Редактор: сервер подсказок на Дане (сейчас - `server.py`), поиск ссылок, переименование, быстрые исправления в редакторе.
2. Серверные программы: PostgreSQL, WebSocket, Redis - три отдельных модуля.
3. Онлайн-песочница в WebAssembly и учебник с запуском примеров в браузере.
4. Сборка больших проектов по модулям (пересобираются только изменённые); LTO и PGO.
5. Удобство: примеры к каждой встроенной функции в справочнике и в подсказках редактора.
6. Публичные замеры против C, Go, Rust и Python, обновляемые при каждом выпуске (`zamery.py`, с версиями компиляторов, флагами и машиной).
7. Установщик для Windows из семени и страница «как пересобрать выпуск и сверить контрольную сумму».

## Чего не делаем и почему

| Что | Почему | Чем заменено |
|---|---|---|
| LLVM | код C уже даёт Windows, Linux, macOS, ARM, WebAssembly, RISC-V (через gcc и clang) | порождение кода C |
| JIT | быстрые вычисления достигаются сборкой заранее и векторными командами; JIT добавил бы сложность без выигрыша на целевых задачах | `-O3`, векторные ядра |
| Сборщик мусора | важны предсказуемые задержки и малая память | значения без общих ссылок и подсчёт мест: память освобождается в известных местах программы (spec.md, раздел 13) |
| async/await | модель параллельной работы - потоки, а не сопрограммы | пул потоков, `параллельно для`, задачи и каналы |
| Английские ключевые слова и сообщения | противоречит идее языка | русская запись и подсказки по привычкам других языков |
| Сбор статистики использования | программы работают без интернета и ничего не отправляют | замеры и тесты в репозитории |
| Обещания скорости без замера | заявление без записи нельзя проверить | `замеры/результаты.md` |

## Простые задачи для первого вклада

Эти задачи не входят в план выше: они открыты всегда и не задерживают выпуски.

- Новые примеры в папке `примеры` и задачи для `dan задачи`.
- Небольшие модули библиотеки на самом Дане (`библиотека/`): YAML, TOML, разбор аргументов командной строки, журнал.
- Новые образцы для фаззинга (`фаззинг/корпус`) и программы для папки `каталог` - набора программ, на которых каждая проверка сверяет вывод.
- Исправления неточностей в `справочник.md` и учебнике.

Перед началом прочитайте `УЧАСТИЕ.md`: каждое изменение - с тестом, в `main` попадает только запрос на слияние с зелёной проверкой.
