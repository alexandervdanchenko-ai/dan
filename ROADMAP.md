# План развития Дана

Главная цель ближайших выпусков - быстрые вычисления на обычном компьютере, вплоть до запуска локальных языковых моделей без видеокарты (4 ядра, 8 ГБ памяти). Подробности о выпущенном - в `CHANGELOG.md`, правила участия - в `УЧАСТИЕ.md`.

## Сделано недавно

- `-O3` для `dan собрать` и `dan запустить`, заранее собранная среда выполнения, быстрые тесты.
- Компилятор написан на самом Дане и собирается из семени на C (`semya/dan.c`) без Python; компилятор на Python заморожен и служит эталоном.

## Сейчас: выпуск 1.5

- Плотные массивы чисел (`массив<дроб32>`, `массив<дроб16>`, `массив<цел8>` и другие), отображение файла в память, передача массивов в функции C без копии.
- Векторные вычисления в среде (скалярное произведение, матрица на вектор и на матрицу, softmax, нормировки, веса Q8) с выбором варианта по процессору, пул потоков.
- Анализ диапазонов значений: доказуемо лишние проверки границ и переполнения убираются; `параллельно для`.

## Дальше

1. Модуль `модели`: локальные языковые модели (GGUF) через llama.cpp, затем собственный движок на Дане со сжатием весов и кэша.
2. Редактор: сервер подсказок на Дане (сейчас - `server.py`), поиск ссылок, переименование, быстрые исправления в редакторе.
3. Серверные программы: PostgreSQL, WebSocket, Redis; модули YAML и TOML.
4. Онлайн-песочница в WebAssembly; сборка больших проектов по модулям; LTO и PGO.
5. Публичные замеры против C, Go, Rust и Python, обновляемые при каждом выпуске.

## Чего не делаем

async/await, LLVM, JIT, сборщик мусора, английские ключевые слова, обещания скорости без записи в `замеры/`.

## Простые задачи для первого вклада

- Новые примеры в папке `примеры` и задачи для `dan задачи`.
- Модули библиотеки на самом Дане (`библиотека/`): YAML, TOML, разбор аргументов командной строки, журнал.
- Новые образцы для фаззинга (`фаззинг/корпус`) и программы для папки `каталог`.
- Исправления неточностей в `справочник.md` и учебнике.

Перед началом прочитайте `УЧАСТИЕ.md`: каждое изменение - с тестом, в `main` попадает только запрос на слияние с зелёной проверкой.
