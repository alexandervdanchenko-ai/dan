# Дан для Visual Studio Code

Поддержка языка программирования [Дан](https://github.com/alexandervdanchenko-ai/dan):

- подсветка ключевых слов, типов, строк, чисел и комментариев;
- поиск ошибок при наборе - те же сообщения, что у компилятора;
- подсказки: ключевые слова, функции библиотеки с описанием, имена программы, общие имена подключённых модулей после «модуль.»;
- описание функции при наведении указателя, переход к объявлению (F12), список функций и типов файла;
- быстрые исправления (Ctrl+.): опечатки в именах и привычки Python заменяются так же, как командой «dan исправить»;
- единый вид текста (Shift+Alt+F);
- запуск программы (Ctrl+F5 или кнопка в заголовке редактора), сборка и проверка из палитры команд (Ctrl+Shift+P, «Дан: ...»);
- запуск в отладчике (F5).

Для работы нужен сам Дан; Python не нужен. Ошибки находит и подсказки даёт компилятор на Дане (`dan сервер`), поэтому редактор знает все возможности языка. Расширение ищет его так: `semya/dan` (`semya\dan.exe`) или `dan.py` в открытой папке, папка из переменной среды `DAN_HOME`, установленный Дан (`%LOCALAPPDATA%\Programs\Dan\dan.exe`), папка `D:\проекты\Дан`, команда `dan` в `PATH`; другой путь (к `dan.exe` или `dan.py`) указывается в настройке «дан.компилятор». Если найден только `dan.py`, расширение запускает его через Python (`python dan.py сервер` передаёт работу компилятору на Дане, когда собран `semya/dan`).

Установка: в Visual Studio Code откройте панель расширений, нажмите «...» и выберите «Установить из VSIX», затем укажите файл `dan-language-1.0.0.vsix` из папки `редактор` репозитория Дана.
