# Дан для программ-агентов

`dan mcp` - сервер Model Context Protocol (MCP): агент вызывает инструменты Дана вместо команд в оболочке. Инструменты: `proverit` (ошибки, как у `dan проверить --json`), `ispravit` (готовые исправления), `zapustit` (собрать и выполнить с пределом времени), `testirovat` (блоки `тест`), `formatirovat` (единый вид) и `spravka` (справка и весь `llms-full.txt` этой версии). Подробно - раздел 14.13 `spec.md`.

Сервер запускается клиентом сам, по stdio. Вместо `dan` подставьте путь к компилятору: в Windows - `dan` установленного Дана, в Linux и macOS - полный путь к `semya/dan` (после `sh semya/sobrat.sh`).

## Claude Code

```
claude mcp add dan -- dan mcp
```

Для всех проектов пользователя: `claude mcp add --scope user dan -- dan mcp`; для проекта, общий с командой (файл `.mcp.json`): `--scope project`.

## Codex

В файле `~/.codex/config.toml`:

```toml
[mcp_servers.dan]
command = "dan"
args = ["mcp"]
```

## Другие клиенты (Cursor, Claude Desktop, Windsurf и подобные)

Запись в файле настроек MCP клиента (`.cursor/mcp.json`, `claude_desktop_config.json` и т. п.):

```json
{
  "mcpServers": {
    "dan": {
      "command": "dan",
      "args": ["mcp"]
    }
  }
}
```

Если клиент не находит Дан, укажите полный путь в `command` и, если исполняемый файл перенесён из папки Дана, переменную `DAN_HOME` в поле `env`.

## Безопасность

`zapustit` и `testirovat` выполняют программы, которые написал агент. Они собираются и выполняются во временной папке (удаляется после выполнения), с пределом времени (по умолчанию 10 секунд) и, в Linux и macOS, памяти (по умолчанию 1024 МБ). Это не песочница: программе доступны сеть и файлы пользователя. Чужой код безопаснее выполнять в отдельной учётной записи, контейнере или виртуальной машине.
