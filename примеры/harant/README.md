# Вопросы с HARANT.RU: монитор и сбор

Три файла на языке Дан:

| Файл | Что это |
|---|---|
| `монитор_harant.dan` | оконное приложение - панель мониторинга ленты вопросов |
| `сбор_вопросов.dan` | то же из командной строки (разовый сбор или наблюдение) |
| `harant.dan` | общий модуль: загрузка, разбор карточек, база, выгрузка |

Обе программы берут вопросы из общедоступной ленты https://harant.ru/questions/ (вход в личный кабинет не нужен) и хранят их в одной базе `вопросы_harant.db` в папке, из которой запущены. Из карточки берутся номер, дата, раздел, автор, заголовок, полный текст (все абзацы), число ответов юристов (без комментариев к ответам, включая свёрнутые под «Еще ответы»), ссылка.

## Монитор (оконное приложение)

```
python dan.py запустить монитор_harant.dan
python dan.py собрать монитор_harant.dan --для=windows     // монитор_harant-windows.exe, без окна консоли
```

В окне:

- **Раздел**, **Слова через запятую** (регистр не важен, можно начало слова: `увольн, зарплат`), **Только вопросы без ответов** - отбор. Под отбор отмечаются ★ новые вопросы, по нему же строится список и таблица.
- **Проверять каждые (мин.)** и **Страниц за проверку** - расписание. Проверка листает ленту, пока на странице есть ранее не виденные вопросы, но не дальше заданного числа страниц.
- **Сообщать окном о новых** - всплывающее сообщение с заголовками новых вопросов; **Обновлять Excel после проверки** - после каждой проверки записывать `вопросы_harant.xlsx` и `.csv` (подходящие под отбор).
- Кнопки **Запустить мониторинг**, **Остановить** (прерывает и идущую проверку), **Проверить сейчас**, **Открыть на сайте** (выбранный вопрос - в браузере), **Выгрузить в Excel** (ровно то, что показано в списке), **Сбросить отметки ★**.
- Строка состояния: лампа (серая - остановлен, зелёная - работает, жёлтая - идёт проверка, красная - последняя проверка с ошибкой), отсчёт до следующей проверки, число вопросов в базе, проверок, новых ★.
- **Показать**: подходящие под отбор / новые за сеанс (★) / все собранные; **Поиск** по номеру, заголовку, тексту и автору.
- Список вопросов, полный текст выбранного вопроса и журнал проверок.

Загрузка идёт отдельной задачей, поэтому окно не замирает. При первом сборе в пустую базу вопросы не отмечаются ★ (это исходное состояние), дальше отмечаются только появившиеся после него. Сбой связи не останавливает мониторинг: ошибка пишется в журнал, следующая проверка - по расписанию. Настройки запоминаются в `монитор_harant.ini`.

## Сбор из командной строки

```
python dan.py запустить сбор_вопросов.dan
python dan.py запустить сбор_вопросов.dan раздел=trudovye-spory страниц=10
python dan.py запустить сбор_вопросов.dan без_ответов=да слова=увольн,зарплат,отпуск
python dan.py запустить сбор_вопросов.dan следить=10
python dan.py запустить сбор_вопросов.dan разделы
```

| Настройка | Значение |
|---|---|
| `раздел=код` | только один раздел; коды выводит команда `разделы` (трудовое право - `trudovye-spory`, семейные дела - `semejnye-spory`) |
| `страниц=5` | сколько страниц ленты пройти (20 вопросов на странице) |
| `без_ответов=да` | в таблицу и на экран - только вопросы без ответов |
| `слова=а,б` | в таблицу и на экран - только вопросы с одним из слов |
| `следить=10` | не завершаться, проверять каждые 10 минут; таблица обновляется после каждого прохода |
| `база=файл.db` | файл базы; таблицы `.xlsx` и `.csv` - рядом с тем же именем |
| `файл=стр.html` | разобрать сохранённую страницу вместо загрузки с сайта |

В базу попадают все увиденные вопросы, отбор применяется к показу и к таблице: так число ответов обновляется у всех вопросов, а признак «дальше всё собрано» не зависит от фильтра.

## Проверка без сети

`образец_страницы.html` - фрагмент настоящей вёрстки сайта (26.10.2026) с добавленными трудными случаями (ссылка и второй абзац в тексте, коды символов, комментарий к ответу):

```
python dan.py запустить сбор_вопросов.dan файл=образец_страницы.html
```

Переменная среды `HARANT_SITE` подменяет адрес сайта (например, `http://127.0.0.1:8765`) - так обе программы проверяются на локальной копии ленты. Если сайт изменит вёрстку, программы сообщат «на странице не найдено ни одного вопроса»; тогда нужно поправить функцию `разобрать_страницу` в `harant.dan`.
