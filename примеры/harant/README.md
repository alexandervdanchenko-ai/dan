# Сбор вопросов с HARANT.RU

Программа на языке Дан `сбор_вопросов.dan` собирает вопросы граждан из общедоступной ленты https://harant.ru/questions/ (вход в личный кабинет не нужен) в базу SQLite и выгружает их в Excel и CSV.

Из каждой карточки берутся: номер вопроса, дата и время, раздел права, имя автора, заголовок, полный текст (с переносами строк), число ответов юристов, ссылка.

## Запуск

```
python dan.py запустить сбор_вопросов.dan
python dan.py запустить сбор_вопросов.dan раздел=trudovye-spory страниц=10
python dan.py запустить сбор_вопросов.dan без_ответов=да слова=увольн,зарплат,отпуск
python dan.py запустить сбор_вопросов.dan следить=10
python dan.py запустить сбор_вопросов.dan разделы
```

Собранная программа для Windows запускается так же: `сбор_вопросов_harant.exe раздел=trudovye-spory страниц=10`.

| Настройка | Значение |
|---|---|
| `раздел=код` | только один раздел; коды выводит команда `разделы` (трудовое право - `trudovye-spory`, семейные дела - `semejnye-spory`) |
| `страниц=5` | сколько страниц ленты пройти (20 вопросов на странице) |
| `без_ответов=да` | только вопросы, на которые ещё никто не ответил |
| `слова=а,б` | только вопросы, где в заголовке или тексте есть одно из слов (регистр не важен, можно начало слова) |
| `следить=10` | не завершаться, проверять новые вопросы каждые 10 минут и печатать их |
| `база=файл.db` | файл базы, по умолчанию `вопросы_harant.db`; таблицы `.xlsx` и `.csv` создаются рядом с тем же именем |
| `файл=стр.html` | разобрать сохранённую страницу (HTML) вместо загрузки с сайта |

Повторный запуск дописывает только новые вопросы, у уже собранных обновляет число ответов. В режиме наблюдения листание останавливается на первой странице, где нет ни одного нового вопроса. Между запросами к сайту - пауза 2 секунды.

`образец_страницы.html` - фрагмент настоящей вёрстки сайта (26.10.2026) для проверки разбора без сети:

```
python dan.py запустить сбор_вопросов.dan файл=образец_страницы.html
```

Если сайт изменит вёрстку, программа сообщит «на странице не найдено ни одного вопроса»; тогда нужно поправить шаблоны в функции `разобрать_страницу`.
