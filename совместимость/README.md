# Проверка совместимости

Здесь хранятся программы, которые каждая следующая версия компилятора Дана обязана выполнять так же, как версия, в которой они были записаны. Каждая папка соответствует редакции языка.

Папка `2026` - копия каталога программ на момент выхода Дана 1.0:

- `программы` - верные программы с указанием `редакция 2026` в первой строке и их точный вывод (`.вывод`), а для программ с вводом с клавиатуры - подаваемый ввод (`.ввод`);
- `ошибки` - неверные программы (без указания редакции, то есть по правилам первой редакции). Каждая из них и дальше должна отклоняться: ошибка записи или типов остаётся ошибкой при сборке, ошибка выполнения - ошибкой выполнения. Текст сообщений может становиться точнее, поэтому он сравнивается только в каталоге, а не здесь. Исправленные варианты (`.исправлено.dan`) должны собираться и выводить записанное в `.исправлено.вывод`.

Файлы этой папки никогда не изменяются: файл `СУММЫ` содержит их контрольные суммы SHA-256, и тест `test_sovmestimost.py` проверяет и суммы, и поведение каждой программы. Если изменение компилятора ломает хотя бы одну программу отсюда, это несовместимое изменение: оно допустимо только в новой редакции языка (раздел 16 спецификации), для которой создаётся новая папка, а старые программы продолжают выполняться по правилам своей редакции.
