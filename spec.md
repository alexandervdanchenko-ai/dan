## 1. Общие положения

Дан - компилируемый язык программирования общего назначения со статической типизацией, русскими ключевыми словами и компактной записью. Главный приоритет - скорость выполнения программ.

Программа на Дан хранится в текстовом файле в кодировке UTF-8 с расширением `.dan`. Компилятор переводит программу в код на языке C, который затем компилируется в исполняемый файл.

## 2. Лексические правила

### 2.1. Строки и инструкции

Каждая инструкция записывается на отдельной строке. Точка с запятой не используется. Перевод строки внутри круглых `( )` и квадратных `[ ]` скобок не завершает инструкцию, поэтому длинное выражение можно переносить, заключив его в скобки.

### 2.2. Комментарии

Комментарий начинается с `//` и продолжается до конца строки. Компилятор его пропускает.

```
// это комментарий
пусть х = 5   // комментарий после кода
```

### 2.3. Имена (идентификаторы)

Имя переменной, функции или типа состоит из букв (русских или латинских), цифр и знака подчёркивания `_` и не может начинаться с цифры. Регистр букв различается: `Сумма` и `сумма` - разные имена. Ключевые слова не могут быть именами.

Буквы `е` и `ё` в именах равнозначны: `счётчик` и `счетчик` - одно и то же имя, так же как `объём_куба` и `объем_куба`. В строках `"..."` буквы, разумеется, не заменяются.

Внутри одного слова имени все буквы должны принадлежать одному алфавиту. Русские «а», «с», «е», «о», «р», «х» и латинские «a», «c», «e», «o», «p», «x» выглядят одинаково, но для компьютера это разные знаки; в других языках такая опечатка незаметно создаёт вторую переменную с тем же видом имени. В Дане она обнаруживается сразу:

```
пусть cумма = 1
```

```
Строка 1, позиция 7: в имени «cумма» смешаны буквы разных алфавитов: «c» (1-я буква, латинская); остальные буквы русские. Вероятно, включена не та раскладка клавиатуры
```

Части имени, разделённые знаком `_` или цифрами, могут быть написаны разными алфавитами: `сжать_gzip`, `хеш_sha256`.

Если имя не объявлено, но похоже на объявленное, сообщение об ошибке предлагает исправление: `переменная «сума» не объявлена; возможно, имелось в виду «сумма»`.

### 2.4. Ключевые слова

| Слово | Назначение |
|---|---|
| `функ` | объявление функции |
| `вернуть` | возврат значения из функции |
| `пусть` | неизменяемая переменная |
| `перем` | изменяемая переменная |
| `если`, `иначе` | условие; `иначе` также задаёт запасное значение (раздел 9.2) |
| `пока` | цикл с условием |
| `для`, `в` | цикл по диапазону или списку |
| `прервать` | досрочный выход из цикла |
| `продолжить` | переход к следующему шагу цикла |
| `и`, `или`, `не` | логические операции |
| `истина`, `ложь` | логические значения |
| `тип` | объявление собственного типа (раздел 8) |
| `ничего` | отсутствие значения необязательного типа (раздел 9) |

### 2.5. Числа

Целые числа записываются цифрами: `0`, `42`, `1000000`. Для удобства чтения допускается знак подчёркивания между цифрами: `1_000_000`.

Дробные числа записываются через точку: `3.14`, `0.5`. Запятая для дробей не используется, так как она разделяет аргументы функций.

### 2.6. Строки

Строка заключается в двойные кавычки: `"Привет"`. Внутри строки действуют специальные последовательности:

| Запись | Значение |
|---|---|
| `\n` | перевод строки |
| `\t` | табуляция |
| `\"` | кавычка |
| `\\` | обратная косая черта |

Строка должна закрываться на той же строке, где открыта.

### 2.7. Операторы и знаки

| Знак | Значение |
|---|---|
| `+ - * /` | сложение, вычитание, умножение, деление |
| `%` | остаток от деления |
| `== !=` | равно, не равно |
| `< <= > >=` | сравнение |
| `=` | присваивание; именованный аргумент (`ф(сумма = 100)`); значение поля по умолчанию |
| `+= -= *= /=` | изменение с присваиванием (`х += 1` то же, что `х = х + 1`) |
| `->` | тип результата функции |
| `..` | диапазон (`1..10` - числа от 1 до 10 включительно) |
| `:` | указание типа (`н: цел`) |
| `,` | разделитель |
| `.` | обращение к полю, свойству или функции значения (`с.оклад`, `с.длина`, `с.добавить(1)`) |
| `?` | необязательный тип (`стр?`, `Сотрудник?`) |
| `^` | степень (`2 ^ 10`); надстрочные `²` и `³` означают `^ 2` и `^ 3`: `х²` |
| `( ) { }` | скобки; `{ }` также записывают словарь (`{"а": 1}`) и тип словаря (`{стр: цел}`) |
| `[ ]` | список, элемент списка, тип списка (`[1, 2]`, `с[0]`, `[цел]`) |

### 2.8. Школьная запись действий

Действия можно записывать так же, как в учебнике и в тетради. Эти знаки полностью равнозначны основным:

| Школьный знак | Основной знак | Пример |
|---|---|---|
| `×` или `·` | `*` | `5 × 2` |
| `:` или `÷` | `/` | `96 : 4` |
| `−` (математический минус) | `-` | `10 − 1` |
| `≤` `≥` `≠` | `<=` `>=` `!=` | `а ≠ 0` |

Двоеточие означает деление только внутри выражения. В объявлениях `пусть х: цел = 10 : 2` первое двоеточие отделяет тип, второе делит.

### 2.9. Невидимые символы

Текст программы записывается в кодировке UTF-8. Метка порядка байтов в самом начале файла (её ставят некоторые редакторы, например Блокнот Windows) пропускается.

Символы управления направлением текста Unicode запрещены в любом месте программы, включая строки и комментарии: U+061C, U+200E, U+200F, U+202A-U+202E, U+2066-U+2069. Такие символы меняют порядок, в котором текст показывается на экране, поэтому человек видит не ту программу, которую выполняет компьютер (атака Trojan Source, CVE-2021-42574):

```
Строка 1, позиция 25: невидимый символ U+202E (смена направления на справа налево): такие символы меняют порядок показа текста на экране и позволяют скрыть настоящий смысл программы; удалите его
```

Вне строк и комментариев недопустимы и прочие невидимые символы (пробел нулевой ширины, неразрывный пробел и другие). Сообщение об ошибке называет такой символ кодом и словами, а не показывает его самого, потому что увидеть его нельзя: `недопустимый невидимый символ U+200B (пробел нулевой ширины)`.

## 3. Типы

| Тип | Содержание | Пример |
|---|---|---|
| `цел` | целое число (64 бита) | `42` |
| `дроб` | дробное число (64 бита) | `3.14` |
| `стр` | строка текста | `"текст"` |
| `лог` | логическое значение | `истина` |
| `рац` | обыкновенная дробь, вычисляется точно | `рац(3, 4)` |
| `мн` | многочлен от `х` с точными коэффициентами | `х² - 3*х + 2` |
| `байты` | последовательность байтов (содержимое файла, сжатые или зашифрованные данные) | `байты("текст")` |

Кроме того, для любого типа `Т` существует тип списка `[Т]`: `[цел]` - список целых чисел, `[стр]` - список строк, `[[цел]]` - список списков целых чисел (таблица). Списки описаны в разделе 7.

Тип словаря `{К: З}` хранит пары «ключ - значение» (раздел 7.5). Для любого типа `Т` существует и необязательный тип `Т?`: значение типа `Т` или `ничего` (раздел 9). Программа может объявлять собственные типы из нескольких полей (раздел 8).

Названия встроенных типов не являются ключевыми словами: это встроенные имена, как и названия собственных типов.

Если тип переменной очевиден из присваиваемого значения, его можно не указывать: `пусть х = 5` означает, что `х` имеет тип `цел`. Тип можно указать явно: `пусть х: дроб = 5.0`.

### 3.1. Обыкновенные дроби

Тип `рац` хранит дробь точно, в виде несократимой пары «числитель / знаменатель» со знаменателем больше нуля. Дробь создаётся функцией `рац`:

| Запись | Значение |
|---|---|
| `рац(3, 4)` | 3/4 |
| `рац(6, 8)` | 3/4 (сокращается автоматически) |
| `рац(5)` | 5 |
| `рац("2 1/3")`, `рац("-3/4")`, `рац("0,75")` | 7/3, -3/4, 3/4 |
| `рац(0.1)` | 1/10 (по записи десятичного числа) |

Дроби складываются, вычитаются, умножаются, делятся и сравниваются как обычные числа, без потери точности: `рац(1, 3) + рац(1, 6)` равно `1/2`. Свойства `д.числитель` и `д.знаменатель` дают части дроби. `вывод` печатает дробь как `3/4`, а дробь со знаменателем 1 как целое число.

Если числитель или знаменатель результата не помещается в тип `цел`, программа останавливается с сообщением об ошибке: точность никогда не теряется незаметно.

### 3.2. Многочлены

Встроенная константа `х` (кириллическая или латинская `x`) - это многочлен первой степени. Из неё, целых чисел и обыкновенных дробей с помощью `+`, `-`, `*`, `^` строятся любые многочлены, а скобки раскрываются автоматически:

```
пусть p = х² - 3*х + 2
вывод((х + 1)^2)            // х² + 2х + 1
вывод((х - 1) * (х + 1))    // х² - 1
```

Знак умножения между числом и `х` обязателен: `3*х`, а не `3х`. Коэффициенты многочлена - точные дроби, поэтому десятичную дробь в многочлен нужно превратить явно: `рац(0.5) * х`.

Деление многочленов: `а / б` - частное, `а % б` - остаток (`(х³ - 1) / (х - 1)` = `х² + х + 1`). Многочлены сравниваются только на равенство. Свойства: `p.степень` (у нулевого многочлена -1) и `p.коэффициенты` - список коэффициентов от старшей степени. `вывод` печатает многочлен в школьной записи: `х² - 3х + 2`, дробные коэффициенты в скобках: `(1/2)х`.

Если в программе объявлена переменная `х`, используется она, а не многочлен.

### 3.3. Правила совместимости типов

Числовые типы образуют ряд `цел` -> `рац` -> `дроб`. Значение можно использовать везде, где ожидается тип правее по ряду: целое число автоматически становится обыкновенной или десятичной дробью, обыкновенная дробь - десятичной. Обратные превращения автоматически не происходят, так как при них теряется точность; для них есть функции `цел`, `рац`, `округлить`.

Арифметика (`+ - * /`) выполняется над числами; результат имеет самый «широкий» из типов операндов: `цел` с `рац` дают `рац`, любой тип с `дроб` даёт `дроб`. Если оба числа целые, результат целый: `7 / 2.0` равно `3.5`, `рац(7) / 2` равно `7/2`, а `7 / 2` равно `3` (см. ниже).

Деление двух целых чисел - это деление с остатком в школьном смысле. Результат `а / б` - частное, `а % б` - остаток, причём всегда выполняется равенство «делимое = частное × делитель + остаток», а остаток не бывает отрицательным и всегда меньше модуля делителя:

| Запись | Частное | Остаток | Проверка |
|---|---|---|---|
| `227492 : 331` | 687 | 95 | 687 × 331 + 95 = 227492 |
| `7 / 2` | 3 | 1 | 3 × 2 + 1 = 7 |
| `-7 / 2` | -4 | 1 | -4 × 2 + 1 = -7 |
| `7 / -2` | -3 | 1 | -3 × (-2) + 1 = 7 |

Для положительных чисел это совпадает с обычным «отбрасыванием дробной части». Для отрицательных Дан следует математическому определению, а не правилу языка C, где остаток может быть отрицательным.

Остаток от деления `%` вычисляется только для целых чисел.

Степень `а ^ н` выполняется раньше умножения и раньше унарного минуса (`-2 ^ 2` равно `-4`) и справа налево (`2 ^ 3 ^ 2` равно `2 ^ 9`). Тип результата: `цел ^ цел` даёт `цел` (`2 ^ 10` = 1024); `рац ^ цел` даёт `рац` (`рац(2, 3) ^ -2` = 9/4); если основание или показатель дробные, результат `дроб` (`2 ^ 0.5`). Целое число в отрицательной степени не является целым, поэтому `2 ^ -1` останавливает программу с подсказкой записать `рац(2) ^ -1`.

Знак `+` также соединяет две строки: `"Дан" + "!"`. Соединять строку с числом напрямую нельзя.

Числа можно сравнивать всеми операциями сравнения. Строки тоже сравниваются всеми операциями: `<`, `>` и другие сравнивают по алфавиту (по кодам символов; буква `ё` при этом стоит после `я`). Логические значения сравниваются только на равенство (`==` и `!=`).

Списки чисел расширяются так же, как числа: список `[цел]` можно использовать там, где ждут `[рац]` или `[дроб]`, а `[[цел]]` - там, где ждут `[[рац]]`. Функция или переменная получает новый список с преобразованными элементами; исходный список не меняется (списки - значения, раздел 7.3). Преобразование проходит по всем элементам, поэтому для очень больших списков удобнее сразу хранить числа нужного типа. Запись списка прямо в месте использования (`пусть с: [дроб] = [1, 2]`) преобразуется при сборке программы и ничего не стоит. Других превращений списков нет: `[стр]` не становится `[цел]`.

Условия после `если` и `пока`, а также операнды `и`, `или`, `не` должны иметь тип `лог`. Число не может служить условием: вместо `если х` пишется `если х != 0`.

## 4. Переменные

```
пусть имя = "Дан"      // изменить нельзя
перем счётчик = 0      // изменить можно
счётчик += 1
```

Попытка изменить переменную, объявленную через `пусть`, является ошибкой компиляции.

Переменная должна получить значение при объявлении. Переменная видна от места объявления до конца блока `{ }`, в котором она объявлена. Объявлять переменную с именем, которое уже видно в этом месте (в том числе во внешнем блоке), нельзя. Имя переменной не может совпадать с именем функции.

## 5. Условия и циклы

```
если х > 0 {
    вывод("положительное")
} иначе если х == 0 {
    вывод("ноль")
} иначе {
    вывод("отрицательное")
}

пока х < 100 {
    х *= 2
}

для ч в 1..10 {
    если ч == 5 { продолжить }
    вывод(ч)
}
```

Условие пишется без скобок, тело всегда заключается в фигурные скобки. Слово `иначе` можно писать как сразу после `}`, так и с новой строки.

Сравнения не записываются цепочкой: вместо `0 < х < 10` пишется `0 < х и х < 10`.

Приоритет операций, от низшего к высшему: `или`; `и`; `не`; сравнения; диапазон `..`; сложение и вычитание; умножение, деление и остаток; унарный минус; вызов функции и обращение через точку. Например, `1..н + 1` означает диапазон от 1 до `н + 1`.

## 6. Функции

```
функ площадь(ширина: дроб, высота: дроб) -> дроб {
    вернуть ширина * высота
}
```

Типы параметров указываются обязательно. Если функция ничего не возвращает, часть `-> тип` опускается.

Аргументы передаются по порядку или по именам параметров. Именованные аргументы делают вызов понятнее, когда параметров несколько, и их можно перечислять в любом порядке; после именованных аргументов позиционные указывать нельзя:

```
функ платёж(сумма: дроб, ставка: дроб, месяцев: цел) -> дроб { ... }

платёж(100000, 0.12, 24)
платёж(сумма = 100000, месяцев = 24, ставка = 0.12)
платёж(100000, месяцев = 24, ставка = 0.12)
```

Именованные аргументы можно передавать функциям программы и при создании значений собственных типов (раздел 8), но не встроенным функциям и функциям библиотеки.

Функции объявляются только на верхнем уровне программы. Параметры функции изменять нельзя: функция получает значения аргументов, а не доступ к переменным вызывающей стороны (раздел 7.3). Функция видит только свои параметры и переменные, объявленные внутри неё; переменные верхнего уровня программы внутри функций не видны, а нужные значения передаются через параметры.

Если у функции указан тип результата, каждый возможный путь её выполнения должен заканчиваться инструкцией `вернуть` со значением этого типа.

Переменная цикла `для` не может изменяться внутри цикла. При переборе диапазона она имеет тип `цел`, при переборе списка - тип элементов списка. Границы диапазона должны быть целыми числами; диапазон используется только в цикле `для`.

`прервать` и `продолжить` допускаются только внутри цикла, `вернуть` только внутри функции.

## 7. Списки

### 7.1. Создание

Список записывается в квадратных скобках через запятую. Все элементы списка имеют один тип, который определяется по элементам; если среди чисел есть хотя бы одно дробное, список имеет тип `[дроб]`.

```
пусть простые = [2, 3, 5, 7]          // [цел]
пусть цены = [10, 99.5]               // [дроб]
пусть имена = ["Аня", "Борис"]        // [стр]
пусть таблица = [[1, 2], [3, 4]]      // [[цел]]
перем покупки: [стр] = []             // у пустого списка тип указывается явно
```

### 7.2. Работа со списком

| Запись | Действие |
|---|---|
| `с[и]` | элемент с номером `и`; нумерация начинается с 0 |
| `с[и] = х` | замена элемента (также `+=`, `-=`, `*=`, `/=`) |
| `с.длина` | количество элементов (`цел`) |
| `с.добавить(х)` | добавление элемента в конец |
| `для х в с { }` | перебор элементов по порядку |
| `с[а..б]` | срез: новый список из элементов с номерами от `а` до `б` включительно (`с[а..а-1]` - пустой) |
| `с.вставить(и, х)` | вставка элемента на место `и` (0..`с.длина`) |
| `с.удалить(и)` | удаление элемента с номером `и` |
| `с.содержит(х)`, `с.найти(х)` | есть ли элемент; номер первого такого элемента или -1 |
| `с.копия()` | копия списка; поскольку списки - значения, то же даёт присваивание `перем к = с` |
| `с.обратный()` | новый список в обратном порядке |
| `с.соединить(разделитель)` | для списка строк: одна строка с разделителями |

`содержит` и `найти` работают для элементов любого типа, в том числе для списков списков и значений собственных типов: все значения языка сравниваются на равенство.

Номер элемента должен быть целым числом от 0 до `с.длина - 1`. Обращение по другому номеру останавливает программу с сообщением: `Ошибка выполнения в строке N: индекс 5 за пределами (длина 3)`.

Если во время перебора `для х в с` в список добавляются элементы, цикл дойдёт и до них.

### 7.3. Списки - значения

Список, как число или строка, - значение. После `перем б = а` у переменной `б` свой список: изменение `б` не меняет `а`. Так же список передаётся в функцию, кладётся в поле или в другой список:

```
перем а = [1, 2]
перем б = а
б.добавить(3)
вывод(а)          // [1, 2]
вывод(б)          // [1, 2, 3]
```

Копирование при этом не замедляет программу: присваивание и передача в функцию не копируют элементы, пока список никто не меняет. Копия делается один раз, в момент первого изменения списка, который хранится сразу в нескольких местах; дальнейшие изменения выполняются на месте.

Изменять список (`с[и] = х`, `добавить`, `вставить`, `удалить`) можно, только если он хранится в переменной `перем`, в поле или элементе такого значения:

```
пусть с = [1, 2]
с[0] = 5          // ошибка: «с» объявлена через «пусть»
перем т = [[1], [2]]
т[0].добавить(3)  // можно: изменяется элемент списка в переменной «перем»
```

Функция получает значение аргумента и не может изменить переменную вызывающей стороны; изменённый список она возвращает как результат:

```
функ с_нулём(с: [цел]) -> [цел] {
    перем р = с
    р.добавить(0)
    вернуть р
}
```

Цикл `для х в с` перебирает список таким, каким он был в начале цикла: элементы, добавленные в теле цикла, в переборе не участвуют.

Списки сравниваются на равенство операциями `==` и `!=`: они равны, если у них одинаковая длина и равны все элементы по порядку. Операции `<`, `>` и другие к спискам не применяются.

### 7.4. Строки

Строка - последовательность символов; свойство `.длина` даёт количество символов (а не байтов): `"Дан".длина` равно 3. Символы нумеруются с нуля. Строки неизменяемы: методы и операции возвращают новые строки.

| Запись | Результат | Пример для с = "Иванов Иван" |
|---|---|---|
| `с[и]` | символ с номером `и` (строка из одного символа) | `с[0]` = "И" |
| `с[а..б]` | символы с номерами от `а` до `б` включительно | `с[0..5]` = "Иванов" |
| `с.найти(т)` | номер первого вхождения `т` или -1 | `с.найти("Иван")` = 0 |
| `с.содержит(т)` | `лог`: есть ли `т` в строке | истина |
| `с.начинается(т)`, `с.оканчивается(т)` | `лог`: начинается или оканчивается ли на `т` | |
| `с.заменить(а, б)` | все вхождения `а` заменены на `б` | `с.заменить("Иван", "Пётр")` = "Пётров Пётр" |
| `с.разбить()` | `[стр]`: слова, разделённые пробелами, табуляцией и переводами строк | ["Иванов", "Иван"] |
| `с.разбить(р)` | `[стр]`: части между разделителями `р` (пустые части сохраняются) | `"а,,б".разбить(",")` = ["а", "", "б"] |
| `с.прописные()`, `с.строчные()` | строка прописными (заглавными) или строчными буквами, включая кириллицу и `ё` | "ИВАНОВ ИВАН" |
| `с.обрезать()` | строка без пробелов, табуляции и переводов строк по краям | |
| `с.символы()` | `[стр]`: список отдельных символов | |
| `с.повторить(н)` | строка, повторённая `н` раз | `"-".повторить(3)` = "---" |

Цикл `для б в с { }` перебирает символы строки. Обратная операция к `разбить` - метод списка `соединить`: `["а", "б"].соединить(", ")` = "а, б".

Номер символа или граница среза за пределами строки останавливают программу с сообщением `индекс 5 за пределами (длина 3)`. Так же устроены срезы байтов: `б[а..б]`.

### 7.5. Словари

Словарь хранит пары «ключ - значение» и быстро находит значение по ключу. Тип словаря записывается в фигурных скобках: `{стр: цел}` - ключи-строки и целые значения. Ключами могут быть значения типов `цел`, `стр`, `лог`, `рац`; значениями - любые, в том числе списки, словари и собственные типы.

```
перем оклады = {"Иванов": 65000, "Петров": 52000}
оклады["Сидорова"] = 78000          // добавление
оклады["Иванов"] += 5000            // изменение
пусть пустой: {стр: [стр]} = {}     // у пустого словаря тип указывается
```

Запись словаря может занимать несколько строк. Внутри ключа двоеточие отделяет значение, а не делит: в `{"а": 10 : 2}` значение равно 5.

| Запись | Действие |
|---|---|
| `с[к]` | значение по ключу; если ключа нет, программа останавливается с сообщением `в словаре нет ключа "к"` |
| `с[к] = з` | добавление или замена значения (также `+=` и другие для существующего ключа) |
| `с.найти(к)` | значение типа `З?`: значение или `ничего`, если ключа нет |
| `с.получить(к, запасное)` | значение или запасное, если ключа нет: `счёт.получить(слово, 0)` |
| `с.содержит(к)` | `лог`: есть ли ключ |
| `с.удалить(к)` | удаление пары (если ключа нет, ничего не происходит) |
| `с.длина` | число пар |
| `с.ключи()`, `с.значения()` | списки ключей и значений |
| `для к в с { }` | перебор ключей |
| `с.копия()` | копия словаря |

Пары хранятся в порядке добавления: в этом порядке словарь перебирается и выводится, поэтому результат программы не меняется от запуска к запуску. `вывод` показывает словарь так: `{"Иванов": 70000, "Петров": 52000}`.

Словари, как и списки, - значения (раздел 7.3): после `перем б = а` у `б` свой словарь, копия делается при первом изменении. Изменять можно словарь в переменной `перем`, его элемент или поле. Словари сравниваются на равенство: они равны, если у них одинаковые ключи и по каждому ключу равны значения; порядок пар не важен.

Пример: подсчёт слов.

```
перем счёт: {стр: цел} = {}
для слово в "мама мыла раму мама".разбить() {
    счёт[слово] = счёт.получить(слово, 0) + 1
}
вывод(счёт)        // {"мама": 2, "мыла": 1, "раму": 1}
```

## 8. Собственные типы

### 8.1. Объявление

Собственный тип описывает значение, состоящее из нескольких именованных частей - полей. Он объявляется словом `тип` на верхнем уровне программы:

```
тип Адрес {
    город: стр
    улица: стр = ""
}

тип Сотрудник {
    фио: стр
    оклад: цел = 0
    адрес: Адрес
    отдел: стр? = ничего
    навыки: [стр] = []
}
```

Поля записываются каждое на своей строке или через запятую: `тип Точка { х: дроб, у: дроб }`. Поле может иметь значение по умолчанию (после `=`); оно вычисляется заново при создании каждого значения и не может обращаться к переменным программы. Типом поля может быть любой тип языка, в том числе другой собственный тип, список и необязательное значение. Тип можно использовать в программе и до места его объявления. Название типа не может совпадать с именем встроенного типа, функции или переменной. Названия собственных типов принято писать с заглавной буквы.

### 8.2. Создание значения

Значение создаётся записью, похожей на вызов функции. Поля перечисляются по порядку или по именам (`имя = значение`); поля со значениями по умолчанию можно не указывать:

```
пусть офис = Адрес("Москва", "Тверская")
пусть сотрудник = Сотрудник(фио = "Иванов И.И.", оклад = 65000, адрес = офис)
пусть новый = Сотрудник("Петров П.П.", адрес = Адрес(город = "Тверь"))
```

После именованных значений позиционные указывать нельзя. Компилятор сообщает о пропущенных полях (`для типа Сотрудник не задано: «адрес»`), о несуществующих полях с подсказкой похожего имени и о значениях неподходящего типа.

### 8.3. Поля

Поле читается через точку: `сотрудник.оклад`, `сотрудник.адрес.город`. Изменить поле можно у переменной, объявленной через `перем`, и у элемента списка:

```
перем с = Сотрудник("Иванов И.И.", адрес = офис)
с.оклад += 5000
с.адрес.улица = "Арбат"

перем штат: [Сотрудник] = [с]
штат[0].оклад = 70000
```

У переменной `пусть`, у параметра функции и у переменной цикла поля неизменяемы.

### 8.4. Значения копируются

Значение собственного типа - это значение, а не ссылка: при присваивании, передаче в функцию и помещении в список создаётся копия. Изменение копии не затрагивает оригинал:

```
перем а = Сотрудник("Иванов И.И.", адрес = офис)
перем б = а
б.оклад = 1
вывод(а.оклад)        // 0: у «а» своё значение
```

Так исключены ошибки, когда изменение в одном месте программы неожиданно меняет данные в другом. Поля-списки тоже копируются: в Дане списки - значения (раздел 7.3).

### 8.5. Вывод и сравнение

`вывод` и `стр(...)` показывают значение вместе с названием типа и полями: `Сотрудник(фио = "Иванов И.И.", оклад = 65000, адрес = Адрес(город = "Москва", улица = "Тверская"), отдел = ничего, навыки = [])`.

Значения одного собственного типа сравниваются операциями `==` и `!=`: они равны, если равны все поля. Для списков таких значений доступны методы `содержит` и `найти`.

### 8.6. Вложенные значения того же типа

Значение не может содержать само себя целиком: тип `тип А { б: А }` был бы бесконечным, и компилятор сообщает об ошибке. Цепочки и деревья строятся через необязательное поле или через список:

```
тип Звено { значение: цел, следующее: Звено? }
тип Папка { имя: стр, вложенные: [Папка] = [] }

пусть дерево = Папка("Дела", [Папка("2025"), Папка("2026", [Папка("Иванов")])])
```

## 9. Необязательные значения

### 9.1. Тип со знаком «?»

В Дане нет нулевой ссылки (`null`): значение любого типа всегда существует. Когда значения может не быть (поиск ничего не нашёл, поле не заполнено), используется необязательный тип - тип со знаком `?`: `цел?`, `стр?`, `Сотрудник?`, `[цел]?`. Отсутствие значения записывается словом `ничего`:

```
функ найти_сотрудника(штат: [Сотрудник], фио: стр) -> Сотрудник? {
    для с в штат {
        если с.фио == фио { вернуть с }
    }
    вернуть ничего
}

пусть отдел: стр? = ничего
пусть оценки = [5, ничего, 4]        // тип [цел?]
```

Значение обычного типа подходит туда, где ждут необязательный: `вернуть с` в функции с результатом `Сотрудник?`. У слова `ничего` тип определяется по месту, поэтому `пусть х = ничего` - ошибка: нужно указать тип (`пусть х: стр? = ничего`).

### 9.2. Проверка перед использованием

Необязательное значение нельзя использовать как обычное: складывать, читать поля, вызывать методы. Компилятор требует сначала проверить, есть ли значение. Так ошибка «обращение к пустому значению», самая частая в других языках, становится невозможной. Есть два способа.

Условие `если пусть` выполняет блок, только если значение есть, и внутри блока даёт к нему доступ под новым именем:

```
если пусть с = найти_сотрудника(штат, "Петров П.П.") {
    вывод(с.оклад)
} иначе {
    вывод("не найден")
}
```

Запасное значение задаётся словом `иначе` внутри выражения: `а иначе б` равно `а`, если значение есть, и `б`, если его нет:

```
вывод(отдел иначе "без отдела")
перем сумма = 0
для о в оценки { сумма += о иначе 0 }
```

Операция `иначе` выполняется последней, раньше неё выполняются все остальные: `а иначе б + 1` означает `а иначе (б + 1)`. Если запасное значение тоже необязательное (`а иначе б`, где `б` имеет тип `цел?`), результат необязательный. Цепочка `а иначе б иначе 0` даёт первое из имеющихся значений, а если нет ни одного, то 0.

### 9.3. Сравнение с «ничего», вывод

Необязательное значение можно сравнить с `ничего`: `найти(с, т) == ничего`, `отдел != ничего`. `вывод` печатает само значение или слово `ничего`.

## 10. Встроенные функции

| Функция | Действие |
|---|---|
| `вывод(значение)` | выводит значение на экран и переводит строку |
| `ввод()` | читает строку, введённую с клавиатуры, и возвращает её (`стр`) |
| `ввод(подсказка)` | то же, но сначала выводит подсказку без перевода строки |
| `стр(х)` | преобразует в строку число, дробь, многочлен, логическое значение или список (так же, как его печатает `вывод`) |
| `цел(х)` | преобразует строку или дробное число в целое |
| `дроб(х)` | преобразует строку или целое число в дробное |

`вывод` печатает строки как есть, а списки - в квадратных скобках, причём строки внутри списка заключаются в кавычки: `["Аня", "Борис"]`.

`ввод` возвращает введённую строку без символа перевода строки. Если вводить больше нечего (данные закончились), возвращается пустая строка `""`.

Правила преобразований:

| Запись | Результат |
|---|---|
| `стр(42)`, `стр(2.5)`, `стр(истина)` | `"42"`, `"2.5"`, `"истина"` |
| `цел("42")`, `цел(" -7 ")` | `42`, `-7` (пробелы по краям допускаются) |
| `цел(7.9)`, `цел(-7.9)` | `7`, `-7` (дробная часть отбрасывается) |
| `дроб("3.5")`, `дроб("3,5")` | `3.5` (дробная часть отделяется точкой или запятой) |
| `дроб(3)` | `3.0` |

Если строку нельзя прочитать как число, программа останавливается с сообщением, например: `Ошибка выполнения в строке 2: строку "тридцать" нельзя преобразовать в целое число`.

Имена встроенных функций и типов нельзя использовать как имена переменных и функций.

## 11. Стандартная библиотека

Функции этого раздела (числа, разряды, деление с остатком, делители и кратные, признаки делимости, простые числа, НОД и НОК) доступны в любой программе без подключения. В отличие от встроенных функций раздела 10, их имена не зарезервированы: если в программе объявлена своя функция или переменная с таким именем, используется она.

| Функция | Результат | Пример |
|---|---|---|
| `модуль(х)` | модуль числа (`цел` или `дроб`) | `модуль(-5)` = 5 |
| `делится(а, б)` | `лог`: делится ли `а` на `б` без остатка | `делится(12, 4)` = истина |
| `чётное(а)` | `лог`: делится ли на 2 | `чётное(308)` = истина |
| `нечётное(а)` | `лог`: даёт ли остаток 1 при делении на 2 | `нечётное(1027)` = истина |
| `простое(а)` | `лог`: ровно ли два делителя (1 и само число) | `простое(97)` = истина |
| `делители(а)` | `[цел]`: все делители по возрастанию | `делители(12)` = [1, 2, 3, 4, 6, 12] |
| `кратные(а, к)` | `[цел]`: первые `к` кратных | `кратные(5, 4)` = [5, 10, 15, 20] |
| `простые_множители(а)` | `[цел]`: разложение на простые множители | `простые_множители(180)` = [2, 2, 3, 3, 5] |
| `нод(а, б)`, `нод(список)` | `цел`: наибольший общий делитель | `нод(12, 9)` = 3, `нод([18, 24, 36])` = 6 |
| `нок(а, б)`, `нок(список)` | `цел`: наименьшее общее кратное | `нок(9, 12)` = 36, `нок([8, 15, 33])` = 1320 |
| `цифры(а)` | `[цел]`: цифры от старшего разряда к младшему | `цифры(635)` = [6, 3, 5] |
| `сумма_цифр(а)` | `цел`: сумма цифр | `сумма_цифр(846)` = 18 |
| `разряды(а)` | `[цел]`: разложение по разрядам без нулевых слагаемых | `разряды(635)` = [600, 30, 5] |

Уточнения:

1. `делители` и `простые_множители` определены для натуральных чисел (1, 2, 3, ...). Для нуля и отрицательных чисел программа останавливается с сообщением об ошибке. У числа 1 делитель один: `[1]`, простых множителей нет: `[]`.
2. Числа 0 и 1 не являются ни простыми, ни составными: `простое(0)` и `простое(1)` равны `ложь`.
3. `нод` и `нок` всегда неотрицательны и работают с отрицательными числами по модулю. `нод(0, 5)` = 5, `нок(0, 5)` = 0. Для списка нужен хотя бы один элемент.
4. `цифры` и `сумма_цифр` для отрицательного числа берут цифры его модуля. `разряды` сохраняют знак: `разряды(-635)` = [-600, -30, -5]; сумма разрядов всегда равна самому числу.
5. `делится(а, 0)` останавливает программу с сообщением о делении на ноль.
6. Вместо `ё` можно писать `е`: `четное`, `нечетное`.
7. Если результат не помещается в тип `цел` (например, `нок` очень больших чисел), программа останавливается с сообщением «результат слишком велик для типа цел».

### 11.1. Дроби, округление, корни

| Функция | Результат | Пример |
|---|---|---|
| `смешанное(д)` | `стр`: запись дроби смешанным числом | `смешанное(рац(7, 3))` = "2 1/3" |
| `смешанное(ц, ч, з)` | `рац`: смешанное число ц ч/з | `смешанное(2, 1, 3)` = 7/3 |
| `периодическая(д)` | `стр`: десятичная запись с периодом в скобках | `периодическая(рац(1, 6))` = "0,1(6)" |
| `округлить(х)` | `цел`: до целого | `округлить(2.5)` = 3 |
| `округлить(х, н)` | до `н` знаков после запятой; при отрицательном `н` - до десятков, сотен и т.д. | `округлить(2.675, 2)` = 2.68, `округлить(1234, -2)` = 1200 |
| `корень(х)` | `дроб`: квадратный корень | `корень(2)` = 1.4142135623730951 |
| `целый_корень(н)` | `цел`: наибольшее целое, квадрат которого не больше `н` | `целый_корень(50)` = 7 |
| `модуль(х)` | модуль числа любого числового типа | `модуль(рац(-3, 4))` = 3/4 |

Округление выполняется по школьному правилу: если первая отбрасываемая цифра 5 или больше, предыдущая увеличивается на единицу (у отрицательных чисел - по модулю). Округляется десятичная запись числа в том виде, в каком оно написано, поэтому `округлить(2.675, 2)` даёт `2.68`, а `округлить(1.005, 2)` даёт `1.01`, хотя в двоичной форме эти числа чуть меньше записанных.

### 11.2. Единицы измерения, пропорции, проценты

| Функция | Результат | Пример |
|---|---|---|
| `перевести(х, из, в)` | `дроб`: перевод величины из одних единиц в другие | `перевести(90, "км/ч", "м/с")` = 25.0 |
| `пропорция(а, б, в)` | `х` из пропорции а : б = в : х | `пропорция(2, 3, 4)` = 6 |
| `процент(число, п)` | п процентов от числа | `процент(200, 15)` = 30 |
| `сколько_процентов(часть, целое)` | сколько процентов составляет часть | `сколько_процентов(30, 200)` = 15 |
| `число_по_проценту(часть, п)` | число, п процентов которого равны части | `число_по_проценту(30, 15)` = 200 |

Пропорции и проценты от целых чисел и обыкновенных дробей вычисляются точно (тип `рац`), от десятичных - в типе `дроб`.

Единицы измерения: длина `мм`, `см`, `дм`, `м`, `км`; масса `мг`, `г`, `кг`, `ц`, `т`; время `с` (`сек`), `мин`, `ч` (`час`), `сут` (`сутки`), `нед`; площадь `мм²`, `см²`, `дм²`, `м²`, `а` (`ар`, `сотка`), `га`, `км²`; объём `мм³`, `см³`, `мл`, `дм³`, `л`, `м³`; скорость `м/с`, `м/мин`, `км/ч`, `км/мин`. Вместо `²` и `³` можно писать цифры: `м2`, `см3`.

### 11.3. Множества

Множество представляется списком без повторов. Результаты операций упорядочены по возрастанию. Работают со списками `[цел]` и `[стр]`.

| Функция | Результат | Пример |
|---|---|---|
| `множество(с)` | элементы без повторов | `множество([3, 1, 3])` = [1, 3] |
| `объединение(а, б)` | элементы, входящие хотя бы в одно | `объединение([1, 2], [2, 3])` = [1, 2, 3] |
| `пересечение(а, б)` | элементы, входящие в оба | `пересечение([1, 2], [2, 3])` = [2] |
| `разность(а, б)` | элементы `а`, которых нет в `б` | `разность([1, 2], [2])` = [1] |
| `подмножество(а, б)` | `лог`: входит ли каждый элемент `а` в `б` | `подмножество([1], [1, 2])` = истина |
| `принадлежит(х, а)` | `лог`: есть ли `х` в `а` | `принадлежит(3, [1, 2])` = ложь |

### 11.4. Статистика

Работают со списками `[цел]`, `[рац]`, `[дроб]`; для пустого списка программа останавливается с сообщением об ошибке.

| Функция | Результат | Пример для [5, 4, 3, 5] |
|---|---|---|
| `сумма(с)` | сумма элементов | 17 |
| `среднее(с)` | среднее арифметическое (`дроб`; для `[рац]` - `рац`) | 4.25 |
| `медиана(с)` | середина упорядоченного ряда | 4.5 |
| `мода(с)` | чаще всего встречающееся значение (только `[цел]`; из нескольких - наименьшее) | 5 |
| `размах(с)` | разность наибольшего и наименьшего | 2 |
| `мин(с)`, `макс(с)` | наименьший и наибольший элемент | 3 и 5 |
| `мин(а, б)`, `макс(а, б)` | меньшее и большее из двух чисел | |
| `упорядочить(с)` | новый список по возрастанию (также `[стр]`) | [3, 4, 5, 5] |

### 11.5. Геометрия

| Функция | Формула |
|---|---|
| `периметр_прямоугольника(а, б)` | 2 × (а + б) |
| `площадь_прямоугольника(а, б)` | а × б |
| `периметр_квадрата(а)` | 4 × а |
| `площадь_квадрата(а)` | а² |
| `площадь_треугольника(основание, высота)` | основание × высота : 2 |

Результат имеет тип аргументов (для целых сторон площадь прямоугольника целая, площадь треугольника - `рац`), площадь круга и длина окружности - `дроб`. Вместо `ё` можно писать `е`: `объем_куба`. Число π доступно как константа `пи`.

### 11.6. Многочлены и уравнения

| Функция | Результат | Пример |
|---|---|---|
| `многочлен(к)` | многочлен по списку коэффициентов от старшей степени | `многочлен([1, -3, 2])` = х² - 3х + 2 |
| `значение(p, х)` | значение многочлена при данном `х` (`рац` или `дроб`) | `значение(х² - 1, 3)` = 8 |
| `решить(p)`, `корни(p)` | `[рац]`: рациональные корни уравнения p = 0 по возрастанию | `решить(х² - 3*х + 2)` = [1, 2] |
| `решить(лев, прав)` | то же для уравнения лев = прав | `решить(2*х + 3, 7)` = [2] |
| `решить_приближённо(p)` | `[дроб]`: все действительные корни, в том числе иррациональные | `решить_приближённо(х² - 2)` = [-1.414..., 1.414...] |
| `разложить(p)` | `стр`: разложение на множители с рациональными корнями | `разложить(6*х² - 5*х + 1)` = "(3х - 1)(2х - 1)" |
| `вынести_общий_множитель(p)` | `стр`: вынесение общего множителя за скобки | `вынести_общий_множитель(2*х² + 6*х)` = "2х(х + 3)" |
| `дискриминант(а, б, в)`, `дискриминант(p)` | б² - 4ав | `дискриминант(1, -3, 2)` = 1 |
| `корни_квадратного(а, б, в)` | `[дроб]`: действительные корни а·х² + б·х + в = 0 | `корни_квадратного(1, -3, 2)` = [1.0, 2.0] |
| `решить_систему(м)` | `[рац]`: решение системы линейных уравнений | см. ниже |

`решить` находит рациональные корни точно (по теореме о рациональных корнях); корни, которые не являются рациональными числами (например, √2), он не возвращает - для них служит `решить_приближённо`, где каждый корень вычисляется с точностью до последнего знака типа `дроб`. Кратный корень указывается один раз. Если уравнение верно при любом `х` (например, `решить(х, х)`), программа останавливается с сообщением об этом.

В `разложить` множитель с корнем p/q записывается как (qх - p), кратные множители - со степенью: `(х - 2)²`. Многочлен, у которого нет рациональных корней, остаётся в скобках: `(х - 2)²(х² + 1)`.

Система из N линейных уравнений записывается списком из N строк; каждая строка содержит N коэффициентов при неизвестных и свободный член. Система 2х + у = 5, х - у = 1:

```
вывод(решить_систему([[2, 1, 5], [1, -1, 1]]))     // [2, 1]: х = 2, у = 1
```

Решение выполняется методом Гаусса в точных дробях. Если система не имеет решений или имеет бесконечно много решений, программа останавливается с соответствующим сообщением.

### 11.7. Неравенства и модуль

| Функция | Результат |
|---|---|
| `решить_неравенство(лев, знак, прав)` | `стр`: множество решений неравенства |
| `решить_систему_неравенств(левые, знаки, правые)` | `стр`: пересечение решений нескольких неравенств |
| `решить_с_модулем(лев, прав)` | `стр`: решения уравнения \|лев\| = прав |
| `решить_неравенство_с_модулем(лев, знак, прав)` | `стр`: решения неравенства \|лев\| знак прав |

Знак записывается строкой: `"<"`, `"<="` (или `"≤"`), `">"`, `">="` (`"≥"`), `"="`, `"!="` (`"≠"`). Неравенства решаются методом интервалов для многочленов любой степени. Ответ записывается в школьной форме:

| Ответ | Смысл |
|---|---|
| `(2; +∞)` | все числа больше 2 |
| `[-2; 2]` | от -2 до 2 включительно |
| `(-∞; -2) ∪ (2; +∞)` | объединение промежутков |
| `{-1; 4}` | отдельные числа |
| `(-∞; +∞)` | любое число |
| `нет решений` | решений нет |

Рациональные границы записываются точно (`1/2`), иррациональные - с четырьмя знаками после запятой (`1,4142`).

```
вывод(решить_неравенство(х² - 4, "<=", 0))                        // [-2; 2]
вывод(решить_систему_неравенств([2*х - 4, х], [">", "<="], [0, 5])) // (2; 5]
вывод(решить_с_модулем(2*х - 3, 5))                               // {-1; 4}
вывод(решить_неравенство_с_модулем(х - 1, "<", 2))                // (-1; 3)
```

### 11.8. Файлы, сжатие, шифрование, архивы

#### Тип `байты`

Значение типа `байты` - неизменяемая последовательность байтов (чисел от 0 до 255). Так представляются содержимое произвольного файла, сжатые и зашифрованные данные.

| Запись | Результат |
|---|---|
| `байты("текст")` | байты текста в кодировке UTF-8 |
| `байты([104, 105])` | байты из списка чисел 0-255 |
| `стр(б)` | текст из байтов (UTF-8) |
| `б.длина`, `б[и]` | количество байтов и байт с номером `и` (число 0-255) |
| `а + б`, `а == б` | соединение и сравнение |

`вывод` печатает байты кратко: `байты(6): d0 94 d0 b0 d0 bd` (не больше 32 первых байтов).

#### Файлы и папки

Пути к файлам записываются строками; можно использовать русские буквы и пробелы, разделитель папок `/` (в Windows также `\`).

| Функция | Действие |
|---|---|
| `прочитать(путь)` | `стр`: текст файла (метка UTF-8 в начале пропускается, окончания строк `\r\n` становятся `\n`) |
| `прочитать_байты(путь)` | `байты`: содержимое файла без изменений |
| `записать(путь, текст)`, `записать(путь, байты)` | записать файл (существующий файл заменяется) |
| `дописать(путь, текст)` | дописать текст в конец файла |
| `существует(путь)` | `лог`: есть ли такой файл или папка |
| `размер_файла(путь)` | `цел`: размер в байтах |
| `удалить_файл(путь)` | удалить файл |
| `создать_папку(путь)` | создать папку вместе с недостающими родительскими |
| `список_файлов(папка)` | `[стр]`: имена файлов и папок по алфавиту; имена папок оканчиваются на `/` |

Если файл не удаётся открыть, программа останавливается с сообщением, например: `Ошибка выполнения в строке 3: не удалось открыть файл "отчёт.txt": файл или папка не найдены`.

#### Контрольные суммы и хеш

| Функция | Результат |
|---|---|
| `контрольная_сумма(данные)` | `цел`: CRC-32 (как в zip), для байтов или строки |
| `хеш(данные)` | `стр`: хеш SHA-256 шестнадцатеричными цифрами |
| `шестнадцатеричная(б)`, `из_шестнадцатеричной(с)` | перевод байтов в шестнадцатеричную запись и обратно |
| `числа_байтов(б)` | `[цел]`: список чисел 0-255 |

#### Сжатие

| Функция | Результат |
|---|---|
| `сжать(данные)` | `байты`: данные, сжатые как можно сильнее (LZMA2, формат .xz) |
| `сжать_gzip(данные)` | `байты`: сжатие DEFLATE в формате gzip (как в zip) |
| `распаковать(данные)` | `байты`: исходные данные (формат .xz или gzip определяется автоматически) |

`данные` - байты или строка. Сжатые данные можно сохранить в файл с расширением `.xz` или `.gz` и открыть архиваторами 7-Zip и WinRAR; Дан, в свою очередь, распаковывает файлы .xz и .gz, созданные другими программами.

`сжать` использует алгоритм LZMA2, тот же, что в 7-Zip и xz: повторы ищутся в окне до 64 МБ, а выбор способа записи каждого участка делается оптимальным разбором с учётом цены в битах. По степени сжатия это сопоставимо с xz и 7z и значительно лучше zip; на тексте выигрыш у zip обычно 15-20%, а на данных с повторами на большом расстоянии - в разы. В сжатые данные записывается контрольная сумма CRC-64, поэтому повреждение обнаруживается при распаковке: программа останавливается с сообщением «данные повреждены».

`сжать_gzip` быстрее и даёт формат, совместимый со всеми программами, понимающими gzip и zip, но сжимает слабее.

#### Шифрование

| Функция | Результат |
|---|---|
| `зашифровать(данные, пароль)` | `байты`: зашифрованные данные |
| `расшифровать(данные, пароль)` | `байты`: исходные данные |
| `сжать(данные, пароль)` | сжать, затем зашифровать (как 7-Zip и WinRAR с паролем) |
| `распаковать(данные, пароль)` | расшифровать, затем распаковать |

Шифрование выполняется алгоритмом ChaCha20-Poly1305 (стандарт RFC 8439). Ключ получается из пароля функцией PBKDF2-HMAC-SHA256 с 600 000 повторений и случайной «солью», поэтому подбор пароля перебором очень медленный, а одинаковые данные с одинаковым паролем каждый раз шифруются по-разному. Poly1305 защищает данные от незаметного изменения: при неверном пароле или испорченных данных программа останавливается с сообщением «неверный пароль или данные повреждены».

Шифрование не уменьшает объём данных (зашифрованные данные длиннее исходных на 53 байта), поэтому для экономии места данные сначала сжимают, а затем шифруют: именно это делает `сжать(данные, пароль)`.

Формат зашифрованных данных: `DANC`, версия (1 байт), число повторений PBKDF2 (4 байта), соль (16 байтов), одноразовое число (12 байтов), шифротекст, код проверки (16 байтов).

#### Архивы

| Функция | Действие |
|---|---|
| `создать_архив(путь, файлы)` | создать zip-архив из списка файлов |
| `создать_архив(путь, файлы, пароль)` | то же с шифрованием AES-256 |
| `извлечь_архив(путь, папка)` | извлечь все файлы в папку; результат - список имён |
| `извлечь_архив(путь, папка, пароль)` | то же для зашифрованного архива |
| `содержимое_архива(путь)` | `[стр]`: имена файлов в архиве |

Архивы создаются в стандартном формате zip со сжатием DEFLATE (файлы, которые не сжимаются, сохраняются без сжатия) и с именами в UTF-8, поэтому открываются Проводником Windows, 7-Zip и WinRAR. Архивы с паролем шифруются по стандарту WinZip AES-256, который понимают 7-Zip и WinRAR (Проводник Windows такие архивы не открывает). При извлечении поддерживаются архивы других программ со сжатием DEFLATE или без сжатия, в том числе с папками внутри и с шифрованием AES; устаревшее шифрование ZipCrypto не поддерживается. Имена, которые могли бы записать файл за пределы указанной папки (например, `../файл`), отвергаются.

### 11.9. Тригонометрия, логарифмы, округления

Углы задаются в радианах; для перевода служат `в_радианы` и `в_градусы`. Все функции этого раздела, кроме округлений, работают с `дроб` (целое число подходит автоматически). Для тригонометрических функций, кроме русских названий, допускаются привычные школьные обозначения.

| Функция | Результат |
|---|---|
| `синус(х)`, `косинус(х)`, `тангенс(х)`, `котангенс(х)` (`sin`, `cos`, `tg`, `ctg`) | тригонометрические функции |
| `арксинус(х)`, `арккосинус(х)`, `арктангенс(х)`, `арккотангенс(х)` (`arcsin`, `arccos`, `arctg`, `arcctg`) | обратные тригонометрические функции |
| `логарифм(а, х)` | логарифм числа `х` по основанию `а`: `логарифм(2, 8)` = 3.0 |
| `ln(х)`, `lg(х)`, `экспонента(х)` (`exp`) | натуральный и десятичный логарифмы, е в степени х |
| `корень(х, н)` | корень степени `н`: `корень(27.0, 3)` = 3.0, `корень(-8.0, 3)` = -2.0 |
| `знак(х)` | 1, 0 или -1 |
| `округлить_вниз(х)` (`целая_часть`), `округлить_вверх(х)`, `дробная_часть(х)` | [х], ⌈х⌉ и {х} для `рац` и `дроб` |

Константа `е` (и латинская `e`) равна 2.718281828459045, константа `пи` - 3.141592653589793.

Для табличных углов, кратных 15°, тригонометрические функции дают точные табличные значения: `синус(пи / 6)` равно `0.5`, `косинус(пи / 2)` равно `0.0`, `тангенс(пи / 4)` равно `1.0`. В большинстве других языков `sin(pi / 6)` даёт `0.49999999999999994`, потому что число `пи / 6` в двоичной записи немного меньше точного значения; для остальных углов результат совпадает со стандартной библиотекой C. Логарифм точной степени основания тоже точен: `логарифм(10, 1000)` равно `3.0`.

Значения вне области определения останавливают программу с объяснением: логарифм неположительного числа, арксинус числа больше 1, корень чётной степени из отрицательного числа, тангенс прямого угла.

### 11.17. Линейное программирование

`максимизировать(ц, А, б)` находит наибольшее значение ц·х при ограничениях А·х ≤ б, х ≥ 0, `минимизировать(ц, А, б)` - наименьшее. Расчёт выполняется симплекс-методом в обыкновенных дробях, поэтому ответ точный. Результат типа `[рац]?` - значения переменных или `ничего`, если целевая функция не ограничена. Правые части `б` должны быть неотрицательными.

```
// Производство: прибыль 3 и 5 на единицу, ограничения по трём ресурсам
вывод(максимизировать([3, 5], [[1, 0], [0, 2], [3, 2]], [4, 12, 18]))     // [2, 6]
```

## 12. Порядок выполнения программы

Инструкции верхнего уровня (вне функций) выполняются по порядку сверху вниз. Функции можно вызывать до места их объявления в файле.

## 13. Выполнение программы

### 13.1. Вывод значений

`вывод` печатает значение и переводит строку. Целые числа печатаются полностью. Дробные числа печатаются кратчайшей записью, которая точно соответствует числу, и всегда с точкой: `10.0`, `0.5`, `3.5`; очень большие и очень малые числа печатаются в экспоненциальной форме: `1e+20`. Логические значения печатаются словами `истина` и `ложь`.

Дробные числа хранятся в двоичной форме, поэтому некоторые десятичные дроби представляются неточно: `0.1 + 0.2` печатается как `0.30000000000000004`. Так ведут себя дробные числа во всех распространённых языках.

### 13.2. Ошибки выполнения

Деление целого числа на ноль и вычисление остатка от деления на ноль останавливают программу с сообщением: `Ошибка выполнения в строке N: деление на ноль`. Деление дробного числа на ноль ошибкой не считается и даёт бесконечность.

Так же останавливают программу обращение к несуществующему элементу списка, неудачное преобразование строки в число и недопустимые аргументы функций математической библиотеки (разделы 7.2, 10 и 11).

### 13.3. Переполнение целых чисел

Тип `цел` вмещает числа от -9 223 372 036 854 775 808 до 9 223 372 036 854 775 807 (64 бита на любом компьютере). Если результат сложения, вычитания, умножения, смены знака, деления или возведения в степень не помещается в эти границы, программа останавливается с сообщением `Ошибка выполнения в строке N: результат слишком велик для типа цел`. Неверный результат никогда не выдаётся молча, а поведение программы не зависит от компилятора и оптимизаций.

Цена этого правила - проверка после каждого действия с целыми числами: на цикле, состоящем только из арифметики, программа работает примерно на 15-20% медленнее, чем без проверок; в обычных программах разница меньше. Для приближённых вычислений с очень большими числами предназначен тип `дроб`; целые числа неограниченной длины запланированы (см. `принципы.md`).

Цикл `для к в а..б` правильно работает при любых границах, включая наибольшее целое число.

### 13.4. Глубина рекурсии

Функция может вызывать сама себя (прямо или через другие функции). Каждый незавершённый вызов занимает место в памяти вызовов (стеке), поэтому глубина рекурсии ограничена: от десятков до сотен тысяч вложенных вызовов в зависимости от функции и системы. Если предел достигнут (как правило, из-за отсутствия условия остановки), программа останавливается с сообщением, а всё, что она вывела до этого, сохраняется:

```
Ошибка выполнения в строке 1: слишком глубокая рекурсия: функция из этой строки вызвала себя слишком много раз, не завершившись; проверьте условие остановки рекурсии или замените её циклом
```

Номер строки указывает на объявление функции. То же ограничение действует при выводе, сравнении и копировании значений собственных типов, вложенных очень глубоко (например, цепочки из миллионов звеньев `тип Звено { значение: цел, следующее: Звено? }`): программа останавливается с сообщением `значение собственного типа вложено слишком глубоко`. Такие длинные последовательности лучше хранить в списке.

### 13.5. Память

В текущей версии память, занятая строками и списками, не освобождается до завершения программы. Для обычных программ это незаметно; автоматическое управление памятью будет добавлено в одной из следующих версий.

## 14. Вопросы, отложенные до следующих версий

Модули и подключение других файлов, обработка ошибок как значений, функции как значения, обобщённые функции, автоматическое освобождение памяти, параллельные задачи, запись чисел в экспоненциальной форме (`1e30`). Порядок их появления описан в файле `принципы.md`.
