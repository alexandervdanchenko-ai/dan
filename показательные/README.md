# Показательные программы

Рабочие программы общего назначения на Дане - образцы для людей и языковых моделей. Каждая собирается
и проверяется тестом `test_pokazatelnye.py` (и в CI): сеть наружу не нужна, вместо Telegram отвечает
местный сервер, веб-сервис слушает свободный порт на 127.0.0.1. Программы пользуются разбором JSON
в собственные типы (`json.разобрать_в`), поэтому их собирает компилятор на Дане (`dan` версии 1.13 и новее).

| Программа | Что делает | Модули |
|---|---|---|
| `телеграм_бот.dan` | бот для Telegram на длинном опросе: `/start`, `/помощь`, `/слова`, эхо с числом слов | `http`, `json`, `журнал`, `настройки`, `командная_строка` |
| `задачи_сервис.dan` | REST-сервис списка задач: GET/POST/PATCH/DELETE, ответы JSON, база SQLite, журнал запросов | `вебсервер`, `sqlite`, `json`, `журнал`, `командная_строка` |
| `сводка_документов.dan` | папка таблиц Word, Excel и CSV -> сводная книга Excel: все строки, итоги по наименованиям, пропущенное | `word`, `excel`, `csv`, `журнал`, `командная_строка` |
| `дубликаты.dan` | поиск одинаковых файлов по хешу SHA-256 во вложенных папках, отчёт текстом или JSON | `json`, `журнал`, `командная_строка` |

У каждой программы есть справка (`--справка`) и описание в начале файла. Блоки `тест` внутри программ
проверяет `dan тестировать файл.dan`.

## Бот для Telegram

```
TELEGRAM_TOKEN=123456:ABC... dan запустить телеграм_бот.dan
dan запустить телеграм_бот.dan -- --настройки бот.toml
```

Токен - из переменной среды `TELEGRAM_TOKEN` или из файла настроек (`токен`, `адрес_api`, `ожидание`).
Ответы Telegram разбираются в свои типы (`тип Сообщение { текст "text": стр? ... }`): ключи, которых
нет в типе, пропускаются, отсутствующие необязательные поля становятся `ничего`. Сбой сети бот переживает:
ждёт всё дольше (до 6 секунд) и повторяет опрос; токен в журнал не попадает.

## Веб-сервис списка задач

```
dan запустить задачи_сервис.dan -- --порт 8080 --база задачи.db
curl -d '{"title":"Позвонить"}' http://127.0.0.1:8080/задачи
curl -X PATCH -d '{"done":true}' http://127.0.0.1:8080/задачи/1
curl http://127.0.0.1:8080/задачи?готово=да
curl -X DELETE http://127.0.0.1:8080/задачи/1
```

Обработчик запросов - безымянная функция с копией настроек службы; каждый запрос открывает своё
соединение с базой, потому что работники сервера выполняются параллельно. Ошибки клиента - ответы
400/404/405 с `{"error": "..."}`, ошибка базы - 500 и строка журнала.

## Сводка документов

```
dan запустить сводка_документов.dan -- счета --вывод счета/сводка.xlsx
```

В каждом файле ищется таблица с шапкой «Наименование» (или «Товар»), «Количество», «Сумма» - в документе
Word, на любом листе Excel или в CSV (разделитель определяется сам). Суммы считаются в копейках целыми
числами, поэтому итог точен. Неверные строки и файлы без нужной таблицы попадают на лист «Пропущено».

## Поиск дубликатов

```
dan запустить дубликаты.dan -- ~/Загрузки --мин-размер 1024
dan запустить дубликаты.dan -- ~/Загрузки --json > дубликаты.json
```

Хеш считается только для файлов, размер которых встречается несколько раз; две половины списка
хешируются двумя задачами (`запустить`) одновременно. Программа ничего не удаляет.
